# 投稿模板（Word 版）

本刊作者投稿可使用以下 Word 模板。模板按本刊 **LaTeX 模板实测版式参数**制作，并按工具箱 **Word→LaTeX 转换引擎**的支持范围给出了「能转成 LaTeX 的写法示例」：正文引用、数学公式、定理与证明、图表题、参考文献都按可直接转换的格式演示。

| 语言 | 模板 | 适用 |
|---|---|---|
| 中文稿 | [SLCN-submission-template-cn.docx](/templates/SLCN-submission-template-cn.docx) | 中文正文 + 英文题目/摘要页 |
| 英文稿 | [SLCN-submission-template-en.docx](/templates/SLCN-submission-template-en.docx) | 英文正文 + 中文题目/摘要页 |

> 模板内全部为占位示例（「第一作者」「摘要正文……」等），**不含任何真实作者或稿件内容**。版式口径（页面/字号/标题层级/图表题/参考文献）经编辑部 2026-10-24 确认。

## 一、填写说明

1. **标题/作者/摘要/关键词/正文**：直接在占位文本上改写。正文用内置「正文」样式（宋体五号、1.3 倍行距=16.4pt、首行缩进 2 字符）；节标题用「标题 1」「标题 2」样式，手工写编号「1」「1.1」。
2. **正文引用**：统一写带方括号编号的括号形式，与文末参考文献编号一致：
   - 单篇：`（[1]）`；多篇：`（[1，2]）`；带页码（专著）：`（[3]，第45 页）`；带引导语：`参见（[4]）`。
   - 引用标记放在**逗号前、句号后**；**不要**写成裸 `[1]`、`文献[1]` 或叙述式「张三（2020）」（这些不会被自动转换）；也**不要**手打 `\parencite{}`（Word 里的反斜杠会变普通文本）。
   - 作者-年制（可选，不推荐）：`（陈波 2022）`、`（Haack 1974，31-44）`；**不能与编号制混用**。
3. **数学公式**：一律用 Word 内置「插入 → 公式」（OMML）。行内公式、独立公式、分式、上下标、求和、希腊字母、逻辑符号都支持；**不要**用 MathType/OLE 公式、公式截图、Symbol/LogicA 等符号字体。**矩阵请拆成多行公式**，或把 LaTeX 源码另附文本交编辑。独立公式居中、单独成段。
4. **定理、引理、定义、证明**：**一段一条**，段首写「定理1」「引理1」「定义1」「证明」+ 空格；不要用自动编号/文本框，也不要依赖加粗（转换保留标签文字，编辑再套 LaTeX 环境；印刷样式：定理正文楷体、定义正文宋体、证明末 □）。
5. **图与表**：图片单独成段插入（PNG/JPG），**图题在图下方**、**表题在表上方**，题注各只写一次，格式「图1: 说明」「表1: 说明」（图题紧跟图片段落、表题紧跟表格）；表格不要合并单元格/嵌套。题注文字暂不会自动进入 `\caption`（见「已知差异」）。
6. **参考文献**：文末**只写一行「参考文献」**（不要写「二、参考文献」、不要加冒号）；**一条一段**，编号 `[1]…[n]` 连续；体例见下方「本刊参考文献印刷体例」，**不写 [J]/[M] 类型标识**，不要用 GB/T 7714 的「作者. 题名[J]. 刊名, 年(期): 页.」句点体例（转换解析不可靠）。正文引用到的条目才会印出，请确保每条都被引用。
7. **作者信息与基金**：标题页作者行的**脚注**依次写「作者信息：姓名，单位，E-mail：…」「基金项目：…」（基金必须单独一段，不要与作者信息写在同一句）。没有基金/致谢可删除对应行。
8. **英文稿**：正文结束后另起「中文题目/摘要」页（编辑排版用）；**中文稿**正文结束后另起「English Title / Abstract」页。转换时请把 `.docx` **单独放一个目录**（同目录其它 `.docx` 会被当作参考文献附件自动并入，污染 bib）。

## 二、与 LaTeX 模板的逐项对齐清单

| 项目 | LaTeX 参数来源 | Word 模板设置 |
|---|---|---|
| 页面/边距 | `CN_template.tex:33`（B5、五号）+ `SLCN-MIX.sty:75`（版心 130×203mm、上 28.3mm、bindingoffset 1.5cm） | B5 176×250mm；正文区 130×203mm；上 28.3mm；下行 18.7mm；镜像边距 内 27.4/外 18.6mm |
| 正文 | `SLCN-MIX.sty:76-77`（1.3 倍行距、首行缩进 2em）+ ctex 五号 | 宋体 10.5pt / Times New Roman 10.5pt；固定行距 16.4pt；首行缩进 2 字符；两端对齐 |
| 题目/作者 | `SLCN-MIX.sty:135,137`（`\LARGE` 小二、`\large` 小四 + 楷体） | 题目 18pt 宋体居中；作者 12pt 楷体居中 |
| 标题层级 | `SLCN-MIX.sty:165-166`（section 小四 12pt、subsection 五号 10.5pt） | 一级 12pt 黑体、二/三级 10.5pt 黑体；编号 1 / 1.1 / 1.1.1 |
| 摘要/关键词 | `SLCN-MIX.sty:513-518`（摘要块 12cm；标签黑体五号、内容小五 9pt） | 12cm 摘要块；标签 10.5pt 黑体、内容 9pt 宋体；中图分类号 B81 / 文献标识码 A |
| 脚注 | `SLCN-MIX.sty:78`（footnotemargin 2em）；标题页六号 7.5pt | 7.5pt 宋体、行距 11.7pt、左缩进 15pt；作者信息/基金在作者行脚注 |
| 参考文献 | `SLCN-MIX.sty:681-689`（biblatex caspervector；`\bibfont` 小五 9pt；条目间距 0.8mm） | 9pt（英文 10pt）；悬挂缩进 0.72cm；编号 [n]；条目间距 0.8mm |
| 图题/表题 | LaTeX article 默认 caption（10.5pt 居中；「图1: …」「表1: …」） | 「题注」样式 10.5pt 宋体居中；图题在下、表题在上；三线表 |

| 英文摘要页 | `SLCN-MIX.sty:562-640` | 英文题目 15pt Times 加粗、Abstract 小四加粗、正文 10.5pt |
| 中文摘要页 | `SLEN.sty:738-761` | 中文题目三号 16pt、作者 12pt 楷体、「摘　要」12pt 黑体、正文 10.5pt |

## 四、转换到 LaTeX 时的已知差异与替代写法

- **英文期刊条目的刊名**：Word 文末清单转换出的 `.bib` 可能缺 `journal` 字段（示例 `[2]` 实测；其余作者/题名/年/卷期页正确）。编辑用「文献回读校验」补齐后再并回。
- **图题/表题**：转换引擎不读取 Word 题注，会在图片/表格处生成 `【需补充图题/表题】` 占位，题注文字留在正文；编辑在一校时把题注并回 `\caption`。作者只需保证「图/表 + 题注」相邻且只写一次。
- **表格样式**：转换产物是带网格线的 `table/tabular`，不是三线表；三线表由排版阶段套用。作者不要合并单元格或嵌套表格。
- **矩阵/根号**：矩阵转换会丢结构，请拆成多行公式；根号在转换引擎中可正确转成 `\sqrt`，但个别预览器（LibreOffice）显示 OMML 根号可能异常，以 Word/最终 PDF 为准。
- **公式/符号字体**：MathType/OLE 公式只取预览图、不可编辑，请改用 Word 内置公式；Symbol/LogicA 等符号字体的字符会丢失，逻辑符号请直接输入 Unicode 字符（¬、∧、∨、→、∀、∃、⊢、⊨、□、◇）。
- **叙述式引用**：`张三（2020）`、`Haack（1974）` 不会自动转换；请改用 `（[1]）` 形式（或统一的作者-年括号形式）。
- **未引用的条目不印出**：参考文献表只印正文引用到的条目，请确保每条都在正文引用一次。
- **中图分类号/文献标识码**：LaTeX 模板按固定值自动排 B81/A；Word 稿中保留的一行会在转换产物正文再出现一次，编辑删除即可（不影响编译）。
- **页码**：Word 模板页码在页脚（便于作者自查）；正式排版页码在页眉，由 LaTeX 模板生成。
- **源稿目录**：转换时 `.docx` 单独放一个目录，避免同目录其它 `.docx` 被当作参考文献附件自动并入。

> 模板与体例如需调整（版式/示例/字段），请提编辑部统一修改并同步本页与对齐清单。
