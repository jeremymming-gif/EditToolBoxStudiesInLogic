# 投稿模板（Word 版）

本刊作者投稿可使用以下 Word 模板。模板按本刊 **LaTeX 模板的实测版式参数**制作（B5 页面、字体字号、标题层级、摘要关键词、脚注、参考文献、图题表题），作者只需替换占位文本即可。

## 下载

| 语言 | 模板 | 适用 |
|---|---|---|
| 中文稿 | [SLCN-submission-template-cn.docx](/templates/SLCN-submission-template-cn.docx) | 中文正文 + 英文题目/摘要页 |
| 英文稿 | [SLCN-submission-template-en.docx](/templates/SLCN-submission-template-en.docx) | 英文正文 + 中文题目/摘要页 |

> 模板内只有占位示例（「第一作者」「摘要正文……」等），不含任何真实作者或稿件内容。

## 填写说明

1. **标题/作者/摘要/关键词/正文**：直接在占位文本上改写；正文使用内置「正文」样式（宋体五号、行距 1.3 倍、首行缩进 2 字符）。
2. **标题层级**：各级节标题使用「标题 1」「标题 2」样式，手工写编号「1」「1.1」（与 LaTeX 模板一致，转换时由模板自动编号）。
3. **脚注**：Word 的「插入 → 脚注」；标题页作者行脚注填写 **作者信息（姓名/单位/邮箱）**，可选「基金项目」「致谢」两行（没有请删除）。正文注释也直接在脚注中写。
4. **图/表**：图片居中插入，**图题在图下方**；表格用**三线表**，**表题在表上方**；编号写「图1」「表1」，题名格式「图1: 题名」。
5. **参考文献**：列在文末「参考文献」标题下，逐条编号 `[1] [2] …`，体例照模板示例（中文条目用中文标点、英文条目用英文标点）。
6. **英文稿/中文稿**：中文稿请另填文末「English Title / Abstract」页；英文稿请另填文末「中文题目/摘要」页（供编辑排版使用）。
7. 填好后把 `.docx` 交编辑部，由编辑部用工具箱转成可编译的 LaTeX 初排稿（作者无需自己转 LaTeX）。

## 转换到 LaTeX 时的已知差异（替代写法）

- **中图分类号/文献标识码**：LaTeX 模板会按固定值自动排这两项；Word 稿里保留的一行会在转换产物正文中再出现一次。作者可保留（编辑转换后删除该行，不影响编译）。
- **图片/表格**：Word 的图片占位与三线表在转换产物中可能不进入正文排版；图题/表题文字会保留。需要精确排版时由编辑在 `.tex` 中补图/表（模板图片本来就是占位示例）。
- **页脚页码**：Word 模板页码在页脚（便于作者自查）；正式排版页码在页眉，由 LaTeX 模板生成。
