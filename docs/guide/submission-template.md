# 投稿模板（Word 版）

本刊作者投稿可使用以下 Word 模板。模板按本刊 **LaTeX 模板实测版式参数**制作，并按工具箱 **Word→LaTeX 转换引擎**的支持范围给出可直接转换的写法示例；参考文献示例取自编辑部引用库与已刊文献，**按本刊印刷体例**排（不使用 `[J]`/`[M]` 类型标识）。

| 语言 | 模板 | 适用 |
|---|---|---|
| 中文稿 | [SLCN-submission-template-cn.docx](/templates/SLCN-submission-template-cn.docx) | 中文正文 + 英文题目/摘要页 |
| 英文稿 | [SLCN-submission-template-en.docx](/templates/SLCN-submission-template-en.docx) | 英文正文 + 中文题目/摘要页 |

> 模板内为占位示例（题名/作者/摘要等），参考文献示例为**真实已发表文献**；模板不含任何未刊稿件内容。版式口径经编辑部（2026-10-24）确认。

## 一、填写说明

1. **标题**：替换占位题名（中文 ≤20 字；英文每词首字母大写，小章节标题仅句首大写）。
2. **作者**：多位作者写在**同一行**——中文稿作者名之间用**全角空格**分隔（`张三　李四　王五`），英文稿用**半角逗号**分隔（`San Zhang, Si Li, Wu Wang`）；排版阶段会自动分列成每人一行。
3. **作者信息**（标题页作者行的脚注）：逐位作者写「姓名，单位，E-mail：…」，**每位作者一行，不写城市、邮编**；`基金项目：…` 与 `致　　谢：…` 各占一行（没有可删除）。**不要添加通讯作者信封标记**（排版时需删除）。
4. **摘要/关键词**：摘要一般不分段；摘要中**不使用引用编号**，按「作者（年份）」叙述。关键词以中文分号分隔。
5. **正文引用**：
   - 一般情况直接加括号写在正文中：单篇 `（[1]）`；专著并标页码 `（[2]，第45 页）`；同一处多篇 `（[1，5，6]）`（只写一个括号、序号由小到大）。
   - 带引导语（参见、参看、详见等）时，编号**不加括号**：`参见文献[4]`。
   - 引用标记放在**逗号前、句号后**；**不要**写裸 `[1]`、`文献[1]` 作为唯一形式，也不要手打 `\parencite{}`。
   - 作者-年制（可选）：`（陈波 2022）`；不要与编号制混用，叙述式「陈波（2022）」不参与自动转换。
6. **数学公式**：一律用 Word 内置「插入 → 公式」（OMML）：行内公式、独立公式、分式、上下标、求和、希腊字母、逻辑符号均支持；**不要**用 MathType/OLE、公式截图、Symbol/LogicA 符号字体；**矩阵请拆成多行公式**。独立公式居中、单独成段。
7. **定理/引理/定义/证明**：**一段一条**，段首写「定理1」「引理1」「定义1」「证明」+ 空格；不要用自动编号/文本框，不要依赖加粗（转换保留标签文字，编辑再套环境；印刷样式：定理正文楷体、定义正文宋体、证明末 □）。
8. **图与表**：图片单独成段插入（PNG/JPG）；**图题在图下方**、**表题在表上方**，各只写一次，格式「图1: 说明」「表1: 说明」；表格不要合并单元格/嵌套。
9. **参考文献**：文末**只写一行「参考文献」**（不要「二、参考文献」、不要冒号）；**一条一段**，编号 `[1]…[n]` 连续；格式照下方「本刊参考文献印刷体例」（**不写 [J]/[M]**，不写 GB/T 7714 的句点体例）；正文引用到的条目才会印出，请确保每条均被引用。
10. **英文/中文摘要页**：中文稿在正文后另起「English Title / Abstract」页；英文稿另起「中文题目/摘要」页。转换时把 `.docx` **单独放一个目录**（同目录其他 `.docx` 会被当作参考文献附件自动并入）。

## 二、与 LaTeX 模板的逐项对齐清单

| 项目 | LaTeX 参数来源 | Word 模板设置 |

| 正文 | `SLCN-MIX.sty:76-77` + ctex 五号 | 宋体 10.5pt / Times New Roman 10.5pt；固定行距 16.4pt；首行缩进 2 字符；两端对齐 |
| 题目/作者 | `SLCN-MIX.sty:135,137` | 题目 18pt 宋体居中；作者 12pt 楷体居中（多作者同一行、排版分列） |
| 标题层级 | `SLCN-MIX.sty:165-166` | 一级 12pt 黑体、二/三级 10.5pt 黑体；编号 1 / 1.1 / 1.1.1 |
| 摘要/关键词 | `SLCN-MIX.sty:513-518` | 12cm 摘要块；标签 10.5pt 黑体、内容 9pt 宋体；中图分类号 B81 / 文献标识码 A |
| 脚注 | `SLCN-MIX.sty:78` | 7.5pt 宋体、行距 11.7pt、左缩进 15pt；作者信息/基金/致谢在标题页脚注 |

| 图题/表题 | LaTeX article 默认 caption | 题注 10.5pt 宋体居中；图下/表上；「图1: 题」「表1: 题」；三线表 |
| 正文引用 | `RULE:354-356,371-375`（`\ct`→[n]、`\pct`→（[n]）、`\pcp`→（[n]，第N页）） | `（[n]）`/`（[n]，第N 页）`/`（[n，m]）`；引导语 `参见文献[n]`（无括号） |

## 四、转换到 LaTeX 时的已知差异与替代写法

- **引导语式引用**（`参见文献[4]`）印刷体例正确、但转换时保持原文不自动链 `\parencite`，由编辑一校补链；一般括号式 `（[1]）` 可自动转成 `\parencite`。
- **参考文献字段**：Word 清单转 `.bib` 时，英文期刊的刊名、英文编著章节的文集名/出版信息、中文译著的译者、学位论文类型、网络资源 URL 可能缺失或类型判错（引擎现有限制）；请编辑用「文献回读校验」补齐后并回，不影响 `.tex` 编译。示例见模板：转换后个别条目会缺刊名/译者等。
- **图题/表题**：引擎不读取 Word 题注，会在图片/表格处生成 `【需补充图题/表题】` 占位、题注文字留在正文；编辑在一校并入 `\caption`。作者保证「图/表 + 题注」相邻且只写一次即可。
- **表格**：转换产物为带网格线的 `table/tabular`（非三线表），三线表由排版阶段套用；不要合并单元格或嵌套表格。
- **矩阵/根号**：矩阵转换会丢结构（拆成多行公式）；根号可转 `\sqrt`，个别预览器（LibreOffice）显示 OMML 根号可能异常，以 Word/最终 PDF 为准。
- **公式/符号字体**：MathType/OLE 只取预览图、Symbol/LogicA 会丢字；逻辑符号请直接输入 Unicode（¬、∧、∨、→、∀、∃、⊢、⊨、□、◇）。
- **英文稿多作者**：英文版转换目前只能稳定识别第一作者，第二/三作者请编辑在转换后用元数据参数补；中文稿多作者可自动识别。
- **未引用条目不印出**：参考文献表只印正文引用到的条目，请确保每条都在正文引用一次。
- **中图分类号/文献标识码**：LaTeX 模板按固定值自动排 B81/A；Word 稿中保留的一行会在转换产物正文再出现一次，编辑删除即可（不影响编译）。
- **页码**：Word 模板页码在页脚（便于作者自查）；正式排版页码在页眉。

> 模板与体例如需调整（版式/示例/字段），请提编辑部统一修改并同步本页与对齐清单。
