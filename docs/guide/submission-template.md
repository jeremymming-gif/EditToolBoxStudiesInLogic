# 投稿模板（Word 版）

本刊作者投稿可使用以下 Word 模板。模板按本刊**排版规范与已刊体例**制作，并给出可直接采用的写法示例：标题页、正文引用、数学公式（行内/独立与编号/逻辑符号）、定理/引理/命题/推论/定义/公理/例/注/证明、图表与题目、写作规范（标点与书名号/数字与连接号/英文/长引文/脚注）、参考文献（真实文献示例）。参考文献按本刊印刷体例排（不使用 `[J]`/`[M]` 类型标识）。

## 一、填写说明

1. **标题**：替换占位题名（中文 ≤20 字；英文每词首字母大写，小章节标题仅句首大写）。
2. **作者**：多位作者写在**同一行**——中文稿作者名之间用**全角空格**分隔（`张三　李四　王五`），英文稿用**半角逗号**分隔（`San Zhang, Si Li, Wu Wang`）；排版阶段会自动分列成每人一行。
3. **作者信息**（标题页作者行的脚注）：逐位作者写「姓名，单位，E-mail：…」，**每位作者一行，不写城市、邮编**；`基金项目：…` 与 `致　　谢：…` 各占一行（没有可删除）。**不要添加通讯作者信封标记**（排版时需删除）。
4. **摘要/关键词**：摘要一般不分段；摘要中**不使用引用编号**，按「作者（年份）」叙述。关键词以中文分号分隔。
5. **正文引用**：
   - 一般情况直接加括号写在正文中：单篇 `（[1]）`；专著并标页码 `（[2]，第45 页）`；同一处多篇 `（[1，5，6]）`（只写一个括号、序号由小到大）。
   - 带引导语（参见、参看、详见等）时，编号**不加括号**：`参见文献[4]`。
   > 说明：括号式编号与「引导语+裸编号」两种写法均按本刊体例排；叙述式「张三（2022）」请保持原文，由编辑处理。
   - 引用标记放在**逗号前、句号后**；**不要**写裸 `[1]`、`文献[1]` 作为唯一形式，也不要手打排版命令。
   - 作者-年制（可选）：`（张三 2022）`；不要与编号制混用，叙述式「张三（2022）」保持原文。
6. **数学公式**：一律用 Word 内置「插入 → 公式」（OMML）：行内公式、独立公式、分式、上下标、求和、希腊字母、逻辑符号均支持；**不要**用 MathType/OLE、公式截图、Symbol/LogicA 符号字体；**矩阵请拆成多行公式**。独立公式居中、单独成段。
7. **定理/引理/定义/命题/推论/公理/例/证明**：**一段一条**，段首写「定理1」「引理1」「定义1」「命题1」「推论1」「公理1」「例1」+ 空格；「证明」段首写「证明.」+ 内容。定理正文楷体、定义宋体、证明末 □ 由排版样式统一套用（无需手工设置）；**不要**用自动编号/文本框/加粗代替标签；「注」不编号（模板中保留为普通段落说明）。
8. **图与表**：模板 §4 内嵌一张示例图（逻辑推理示意图），**替换为您的图即可**（PNG/JPG；建议另附 PDF/PPT 等矢量源文件）；**图题在图下方、表题在表格下方**（编辑部要求），各只写一次，格式「图1: 说明」「表1: 说明」，且与图/表**紧邻**（排版时按题注位置并入，无需在正文重复写题注）；**表格请用三线表**（表格边框只设上、下框线 + 表头单元格下框线，模板已是三线表）；不要合并单元格/嵌套。
9. **参考文献**：文末**只写一行「参考文献」**（不要「二、参考文献」、不要冒号）；**一条一段**，编号 `[1]…[n]` 连续；格式照下方「本刊参考文献印刷体例」（**不写 [J]/[M]**，不写 GB/T 7714 的句点体例）；正文引用到的条目才会印出，请确保每条均被引用。**投稿时可随稿附参考文献库文件（`.bib`，推荐，初排优先采用）；没有 `.bib` 也可以——初排会按文末清单或手写 `\bibitem` 自动生成参考文献库，条目类型与字段可能需人工核对。**
10. **英文/中文摘要页**：中文稿在正文后另起「English Title / Abstract」页；英文稿的**中文题目/摘要页位于第 2 页**（便于排版核对中文题名/摘要）。投稿时把 `.docx` **单独放一个目录**（同目录其他 `.docx` 可能被当作参考文献相关附件并入，请不要混放无关文件）。
11. **写作规范（模板 §5.1–5.3）**：标点与书名号（全角标点、书名号《》、引号“”/‘’）；数字与连接号（年份/日期写法；短横 `-`、双短横 `–`、一字线 `—` 三种不可混用）；英文规范（英文引文独立成段不加引号、章节标题大小写、et al./p. 8–12）。
12. **长引文与脚注（模板 §5.4–5.5）**：长引文**独立成段、不加引号**（引文段内不要混排脚注）；脚注标记放**逗号前、句号后**且脚注以句号结尾；表格注释请写在表格下方的正文段（「注：……」），不要插入表格单元格，模板已给示例。
13. **独立公式编号与引用**：独立公式居中、单独成段；正文引用公式写「式（1）」「公式（1）」，只要引用编号与独立公式出现顺序一致，排版时即按此编号（**无需手打编号或占位**）；未被正文引用的独立公式保持无编号（与已刊一致）。

## 四、投稿前检查清单（编辑部建议）

- [ ] 文件命名：以**第一作者全拼**命名 `.docx`（如 `ZhangSan.docx`），与投稿体例一致。
- [ ] 只交 `.docx` 终稿：**无修订痕迹、无批注、无隐藏文字**；同目录不要放其他 `.docx`（可能被当作参考文献相关附件并入）。
- [ ] 标题、作者（多作者一行：中文全角空格 / 英文逗号）、单位、E-mail 已填；作者信息在作者行脚注，**不写城市邮编**。
- [ ] 摘要不分段、200–300 字；关键词 3–8 个，用中文分号「；」分隔；英文题目/摘要页已填（英文稿则填中文题目/摘要页）。
- [ ] 正文引用与文末参考文献**编号一一对应**；每条参考文献都在正文引用过（未引用条目不会印出）。
- [ ] 参考文献一条一段、编号 `[1]…[n]` 连续；按本刊体例（无 `[J]/[M]`、无 GB/T 7714 句点体例）；英文期刊名/书名/文集名按模板用斜体标出。
- [ ] 图：图片单独成段（PNG/JPG），**并另附 PDF/PPT 等矢量源文件**；图题在图下方，只写一次。
- [ ] 表：用三线表，不合并单元格；**表注写在表格下方正文段**（不要用表格内脚注）。
- [ ] 公式用 Word 内置公式（OMML），不用 MathType/截图/符号字体；矩阵拆成多行公式；公式编号无需手打。
- [ ] 长引文独立成段不加引号；脚注放逗号前/句号后、以句号结尾。
- [ ] 基金项目、致谢写在标题页脚注（基金一行、致谢一行；没有则删除）。
- [ ] 交稿前请对照以上清单逐项自查；编辑部初排时会核对题名/作者/单位/基金/参考文献/图表题等，若需补充会与作者联系确认。

## 五、写作与提交注意事项（编辑部初排时核对）

- **引用**：编号式 `（[1]）`/`（[1]，第45 页）`/`（[1，5，6]）` 与引导语+裸编号（`参见文献[4]`）均按本刊体例排；叙述式「张三（2022）」保持原文，由编辑处理。
- **参考文献字段**：英文期刊刊名、英文编著章节文集名/出版信息、中英文学位论文类型/学校、网络资源 URL 请按模板写全；个别条目缺字段时编辑部初排会核对并与作者确认（不影响投稿）。
- **图题/表题**：题注请紧邻对象、只写一次；空题注/多题注无法判定时保留原样并由编辑核对。
- **表格**：三线表（表格边框仅上下框线 + 表头下框线）按本刊体例排；其他表格请保持结构简单；不要合并单元格或嵌套。
- **中图分类号/文献标识码**：正文写一行即可，标题页由排版统一印制 B81/A，正文不重复出现。
- **定理/证明**：中文标签「定理1/引理1/定义1/命题1/推论1/公理1/例1」与「证明.」段首按环境排版；「注」不编号（保留普通段落）；英文标签请按模板示例。
- **公式编号**：正文「式（N）/公式（N）」引用与独立公式顺序对齐时按序编号；未引用公式保持无编号（与已刊成品一致）。
- **英文稿多作者**：按「姓名, 单位, E-mail: …」逐行脚注写法填写；中文稿多作者请按模板同法填写。
- **矩阵/根号**：矩阵请拆成多行公式；根号在个别预览器（LibreOffice）中显示可能异常，以 Word/最终 PDF 为准。
- **公式/符号字体**：MathType/OLE 只取预览图、Symbol/LogicA 会丢字；逻辑符号请直接输入 Unicode（¬、∧、∨、→、∀、∃、⊢、⊨、□、◇）。
- **行内公式行距**：模板正文行距用「最小值 16.4pt」（而非固定值），行内较高的公式行会自动撑开、不会被裁切。
- **未引用条目不印出**：参考文献表只印正文引用到的条目，请确保每条都在正文引用一次。
- **页码**：Word 模板页码在页脚（便于作者自查）；正式排版页码在页眉。

> 本页随模板同步更新；如对模板或体例有疑问，请与编辑部联系。

## 六、投稿材料与元数据核对

作者投稿时请一并对齐本刊模板所需的**稿件信息**；信息不全的部分，编辑部初排时会与作者确认。

### 1. 需要提交的材料

- **正文**：`.docx` 终稿（必需）。同目录只放正文与必要的图片/矢量源文件，不要混放其他 `.docx`。
- **图片**：正文内嵌图片（PNG/JPG）；建议另附 PDF/PPT 等矢量源文件。
- **参考文献库**（可选，推荐）：随稿附 `.bib` 文件，初排优先采用。
- **稿件信息**（可选）：题名、作者、单位、E-mail、摘要、关键词、基金、致谢等信息若已在正文或标题页写全，无需另填；若集中在另一份文件里，可随稿提交。

### 2. 格式要求（与模板一致）

- 题名、作者行、作者信息脚注、摘要、关键词、中图分类号·文献标识码、英文题名/摘要页：位置与写法见本页 §一、§二。
- 作者信息脚注逐位作者一行：「姓名，单位，E-mail：…」；基金项目、致谢各占一行（没有则删除）。
- 文件命名：以第一作者全拼命名 `.docx`（如 `ZhangSan.docx`）。

### 3. 常见缺失项（请作者自行核对）

- 第一作者姓名 / 单位 / E-mail 是否齐全；多位作者请逐位写。
- 英文题名、英文作者名、英文单位、英文摘要页是否已填（中文稿同样需要）。
- 表题、图题是否紧邻对象且各只写一次；表格是否为三线表、有无合并单元格。
- 基金项目、致谢是否有遗漏；参考文献编号与正文引用是否一一对应。

### 4. 提交前自查清单

- [ ] 正文 `.docx` 与图片/矢量源文件齐全；同目录没有其他 `.docx`。
- [ ] 标题页作者信息、基金、致谢已填；摘要 200–300 字、关键词 3–8 个。
- [ ] 英文题名/摘要页已填；多作者按模板写法排在同一行。
- [ ] 图题/表题位置正确，表格为三线表。
- [ ] 参考文献每条都在正文引用过；随稿 `.bib`（如有）与文末清单一致。
