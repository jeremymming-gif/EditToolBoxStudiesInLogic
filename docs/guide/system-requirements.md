# 系统要求

> **本页目录**：[一句话定位](#一句话定位) · [平台](#平台) · [依赖](#依赖) · [磁盘与权限](#磁盘与权限) · [自检](#自检) · [限制](#限制)

## 一句话定位

只要系统能运行安装包，工具箱就能做**初排转换**；**编译 PDF** 需要 TeX，**Word 公式图** 需要 LibreOffice。三者可以只具备一部分，工具会按缺什么提示什么，不会假装成功。

## 平台

| 平台 | 支持情况 |
|---|---|
| Windows 10 / 11（x64） | 正式支持，发布 zip 解压即用 |
| macOS 14+（Apple 芯片 / arm64） | 正式支持，发布 `.app` 包 |
| macOS Intel | 官方包不提供，可用源码方式运行 |
| Linux | 未作为发行目标；引擎命令行可以跑，界面未打包 |

## 依赖

| 依赖 | 什么时候必需 | 说明 |
|---|---|---|
| 本应用安装包 | 总是 | 已自带引擎，不需要另装 Python |
| XeLaTeX | 要编译 PDF 时 | TeX Live / MiKTeX / MacTeX 均可；要能调用 `xelatex` |
| biber | 要编译参考文献时 | 与 XeLaTeX 一并安装；要能调用 `biber` |
| LibreOffice | 含 MathType / OLE 公式的 Word 稿 | 用于导出公式图；不装则公式位置留占位 |
| Git | 用引用库的版本与同步时 | 可选；不装则库的提交/回退不可用 |
| 中文字体 | 排版中文时 | Windows 用系统自带字库；macOS 一般自带 |

## 磁盘与权限

- **磁盘**：安装包约几百 MB；每篇稿件转换的中间产物与 PDF 另计，建议留 **2 GB** 以上可用空间。
- **权限**：能读源稿件目录、能写输出目录即可。输出到系统目录才需要管理员权限。
- **网络**：转换、一校核查、清理与合并全部离线；只有 AI 功能与在线更新检查需要联网，且都要你明确确认。

## 自检

装好之后，用**设置中心 → 引擎与环境**跑一次环境检查：九项会逐项给出通过/不通过与修复建议（`engine_bundle` / `xelatex` / `biber` / `libreoffice` / `git` / `disk_space` / `output_writable` / `template_bundle` / `windows_fonts`）。细节见[环境检查与诊断](../reference/environment-check)。

## 限制

- **不打包 TeX**：TeX 分发体积大、升级频繁，工具不自带；请按平台自行安装。
- **Windows 字体**：非 Windows 平台不会假装有 Windows 字体，有的模板字体项会被跳过并在报告里说明。
- **虚拟环境不参与**：应用只认随包的引擎，不会去用你机器上别的 Python 环境。
