# 快速上手

> 本指南假设你已经装好工具箱（Windows 解压即用 / macOS 拖进「应用程序」，见[安装说明](./install)），并以编辑身份使用本工具。
> 桌面端为 **Flet 单壳**：左栏是两级导航（工作台 / 单篇稿件 / 整期装配 / 引用库 / 设置 / 帮助与关于；展开单篇、整期或引用库，子视图与步骤直接列在名下）。

## 单篇稿件：从作者来稿到可编译初排稿

1. 打开工具箱，进入 **工作区 → 单篇稿件**，确认左侧导航停在 **单篇稿件 → 初排转换**；
2. **源稿件（必填）**：点「浏览…」选 `.docx` / `.tex` 来稿，或把路径粘贴进输入框
   （Flet 单壳**不接收系统拖放**，统一走原生文件对话框——已实测记录在[已知限制](../reference/known-limitations)）；
   **输出根目录（必填）**：点「浏览…」选产物根目录；
3. **处理选项**：默认勾选 **编译 PDF**（调用 XeLaTeX，长任务、日志实时滚动）；另有 **清理临时文件**、
   **导出原稿 PDF**（保留原稿并另存一份 PDF 备查）。可展开 **高级参数** 填卷 / 期 / 年 / 页码 / 收稿；
4. 点右上角 **运行**：日志逐行滚到下方日志区；运行中可点 **停止**（终止整棵进程树，不留 xelatex 残留）；
5. 完成后结果横幅给出产物目录（`<作者>/` 下为 `.tex`、`reference.bib`、模板 `.sty`，勾编译时另有 PDF）。
   Word 稿脚注里的文献默认并入 `reference.bib`：纯引用在正文改成括号引用，混合型脚注保留并在日志里提示人工核对。

::: tip 产物与元数据
作者稿里没填的字段会在产物里写成 `【未识别：…，请手工填写】`，日志「注意事项」也会列出；
需要补题名/作者/摘要/关键词时，直接改产物 `.tex` 或使用引擎 CLI 的元数据参数（见 `Engine/docs/ENGINE_API.md`）。
:::

## 单篇的另外两步：文献回读校验与一校核查

- **一校核查**（左侧导航「单篇稿件 → 一校核查」）：选初排稿 `.tex`，按规则列出命中清单；默认只报不改，勾选后可另存修正版。
- **文献回读校验**（旧入口，已迁到「引用库 → 规范化」，见[引用库](../features/bibdb)）：选回读的 `.bib`（可附原稿/初排 tex），
  检查回读条目与正文引用是否一致并给出问题清单；该 GUI 入口只出报告、不并回（并回仅 CLI `checkbib.py` 可用）。退出码 1 = **有命中项，不是失败**。

## 整期装配：一条六步流水线

左侧导航展开 **整期装配**：先「流水线总览」，其下 6 个步骤页；每个步骤页顶部常驻进度带，可单步跑也可全流程：

1. **检查 tex 信息**：确认每篇的卷期号、页码、作者字段（产物为 `信息检查<时间戳>.txt` + `.json`）；
2. **生成目录**：按信息检查报告生成中英目录并落位编译（可只预览，不写盘）；
3. **编译全部**：整期逐篇 `xelatex → biber → xelatex×2`，失败篇目单独列出；
4. **合并文件**：把整期 PDF 合并为可交付的整期文件（书签层级/编委页/封底可选）；
5. **删除临时文件**：三档清理（辅助文件 / 交付收尾 / 工作区旧件），危险动作会二次确认；
6. **目录摘要推送**：按期生成当期目录摘要 `.docx`，可先 dry-run 预览、不写盘。

任一步可 **取消**；日志与进度同屏可见。

## 引用库（查库只读 / 入藏与待裁决写库）

**概况**（条目总数、冲突/待裁决、库文件大小、条目类型分布）与 **查库**（按题名/作者/年份检索）
是只读的。**入藏**与**待处理**是写库页，安全口径统一：

1. 选来源（`.bib` 文件 / 整期目录 / 粘贴 bib 文本）→ **预览**（引擎 `--dry-run`，库一个字节都不动）；
2. **二次确认**后真写，写前带 `--expect-db-sha256` 校验库 sha（预览过期会被引擎拒绝并提示刷新）；
3. 写成功后自动**本地提交**（入藏与待裁决都是每次写库 1 条提交，「全部采用」批量也只 1 条；
   只提交 `bib_db/bibliography.jsonl`、不推送）；「待处理」页的版本库
   状态区可显式「推送…」或「回退到上一个提交…」，两者都要二次确认。

需要脚本化时仍可直用引擎 CLI（`Engine/bibdb.py`），照搬界面的参数顺序即可。

## 设置与帮助

- **设置**：外观（深色模式、界面缩放，随屏幕工作区钳制）、路径（引擎目录 / 私有笔记仓）、日志选项、
  **环境检查**（只读调用 `Engine/envcheck.py --json`，展示 TeX / biber / LibreOffice / 字体 / 磁盘检查）
  与「关于与诊断」；所有设置落盘到本机配置文件，退出时先保存再关闭。
- **帮助与关于**：怎么用、快捷键与交互、IA 15 页映射速览、**边界与安全**（作者来稿只读 / 写库二次确认 / 正文不外发）、版本与许可。
