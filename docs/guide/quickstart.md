# 快速上手

> **本页目录**：[先做一篇](../features/single) · [再做整期](../features/assembly) · [引用库](../features/bibdb) · [设置与搜索](../features/settings) · [下一步](#下一步)

编辑部工具箱是 Flet 单壳应用：文档逻辑都在随包的引擎里，界面只负责取值、拼参数与显示日志。第一次用，按下面顺序走一遍即可。

## 单篇稿件：从作者来稿到可编译初排稿

1. 打开左侧 **工作区 → 单篇稿件 → 初排转换**。
2. 「源稿件」选作者来稿，支持 `.docx` / `.doc`（`.doc` 需先另存为 `.docx`）/ `.tex`；「输出根目录」选这一期的目录。两项都必填。
3. 需要补刊期、稿件信息或附件时展开「稿件信息、附件与元数据（可选）」，留空就沿用自动解析或模板默认值。
4. 输出选项决定是否顺手编译 PDF、是否清理临时文件；其余行为收在「更多输出选项」。
5. 点「开始转换」。运行中可以「停止」；结束后结果横幅给出产物目录，主操作是「打开交付目录」。

::: tip 产物与元数据
产物里会有 `<作者>.tex`、`reference.bib`、勾选编译时的 `<作者>.pdf`，以及 `original/`（源文件夹整目录归档，源文件不动）。元数据里出现的 `【未识别：…】` 表示自动解析没认出该字段，人工补一下即可。模板样式随包提供，不需要另装 `.sty`。
:::

Word 来稿里的脚注文献不用手工搬：正文脚注会被识别为引用并进入 `reference.bib`；识别不出的会留在报告里点名，不会静默丢弃。

## 单篇的另外两步：AI 建议与一校核查

- **AI 辅助初排**：需要 AI 建议时点「使用 AI 辅助初排」，走「准备任务 → 获取结果 → 审阅采纳 → 完成」四步；默认保留原稿，只有你确认后才改。初排编译失败时，工具会先用本机规则尝试自动修复；本机修不好且你要外发时，在「AI 辅助编译修复」里逐篇点「**确认并发送一次**」——一次确认只对应一次发送。
- **一校核查**：选初排后的 `.tex`，默认只出报告（写到 `<名>_一校核查.md`），不动稿件；勾「顺手把无歧义的改掉」才另存 `<名>_一校核查后.tex`。当前共 **29 条规则**，报告只列需要人判的命中；程序退出码 1 表示「有命中，不是失败」。

细节见[单篇稿件](../features/single)。

## 整期装配：一个单页工作台，四个独立功能

打开 **工作区 → 整期装配**，四个功能平铺在同一页，**彼此独立、不要求按顺序执行**：

| 功能 | 什么时候用 |
|---|---|
| **生成目录** | 篇目齐了，要检查 tex 信息并按栏目表生成目录页 |
| **编译并合并** | 各篇都要编译，最后合成整期 PDF（扉页 + 编委页 + 目录 + 各篇 + 封底） |
| **清理临时文件** | 交付后回收编译中间文件（移到回收站，可撤销） |
| **生成推送文案** | 要发目录摘要推送，生成对应 docx |

按当期需要点其中一张卡片就行；某期只想补一份推送文案，就直接跑第四张。整期没有「按顺序执行」的流水线。「生成目录」页的「生成单页目录」默认勾选（强制压到 1 页）；不勾选则允许中英文目录各 1–2 页，超过 2 页报错回滚。细节见[整期装配](../features/assembly)。

## 引用库：先查库，再决定查证与入藏

引用库按「查阅 / 采录 / 治理」三组排布，十个视图加一个独立的「版本与同步」页：

1. **查库**：按 key / 别名 / DOI / 题名检索，复制 BibTeX；只读，不改库。
2. **入藏**：单篇 `.bib`、整期目录或粘贴 bib 文本，先看预演（新增 / 重复 / 冲突），二次确认后才写库。
3. **治理**：待处理、编辑、查重合并、字段归位、库健康都是「先预演、再确认、写一条本地提交」，绝不推送。

口径：往期成品 bib 视为已核实；AI 结果与粘贴文本默认未核实；重复记录只报告、不自动合并。细节见[引用库](../features/bibdb)。

## 设置与搜索

- **设置中心**（`Ctrl+,`）九组一页：外观、引擎与环境、路径、日志与诊断、高级与关于、窗口与托盘、语言与地区、AI 与模型、网络代理。AI 与模型里填 Key / 地址 / 模型与预算；网络代理里可测试连接。细节见[设置中心](../features/settings)。
- **命令面板**（`⌘K` / `Ctrl+K`）搜页面、常用命令与最近记录，不搜稿件正文与日志。细节见[命令面板与搜索](../features/search)。
- 常用快捷键：`F5` 重新检测引擎、`F9` 运行当前步骤、`Esc` 停止、`Ctrl+Shift+D` 切换深浅色。
