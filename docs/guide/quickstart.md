# 快速上手

> 本指南假设你已经装好工具箱（Windows 解压即用 / macOS 拖进「应用程序」，见[安装说明](./install)），并以编辑身份使用本工具。

## 单篇稿件：从作者来稿到可编译初排稿

1. 打开工具箱（Windows 双击 `编辑部工具箱.exe` / macOS 双击 App），进入 **初排转换** 页；
2. 把作者源文件（`.docx` 或 `.tex`）拖到 **源文件（必填）**，把输出目录拖到 **输出目录（必填）**
   （macOS 版可直接拖；Windows 版点「浏览…」选择，或把路径粘贴进输入框）；
3. 按需填写 **正文信息覆盖**（题名、作者、单位、邮箱、摘要、英文题名等）与 **出版信息**（卷/期/年/起止页/收稿日期）；
4. 点 **运行**，观察下半部分运行日志；
5. 产物目录里会得到 `<作者>.tex` + `reference.bib` + 模板 `.sty`。再点 **编译** 即可得到 PDF。

::: tip 占位符是提示，不是错误
作者稿里没填的字段会在产物里写成 `【未识别：…，请手工填写】`；日志「注意事项」也会列出。
按提示在「正文信息覆盖」里补，或直接改产物 `.tex`。
:::

## 参考文献核实（可选）

1. 在 **设置** 页配置自己的 API（密钥只存本机）；
2. 在转换页勾选「用 AI 处理参考文献」，可生成《文献核实任务书》，按需打开「检索证据」；
3. 建议先在 **引用库 → 设置** 打开 **先算账**：跑一次只打印「源 bib N 条 / 正文引用 M 条 / 预计检索与 AI 次数」，
   不检索、不调 AI（零费用）；
4. 核实只针对 **正文实际引用** 的条目（默认上限 120，可在设置里调）；命中引用库的已核实条目会 **跳过** 检索与 AI。

## 文献回读校验与一校核查

编辑按任务书改完 `.bib` 交回后：

- **文献回读校验**：检查回读的 bib 与正文引用是否一致，并给出问题清单；
- 校验通过后，可点 **入藏到引用库** 把这份已核实的 bib 存进编辑部引用库。

## 整期装配

顺序按侧边栏从上到下即可：

1. **检查 tex 信息**：确认每篇的卷期号、页码、作者字段；
2. **编译全部**：整期逐篇编译，失败会标出；
3. **生成目录**：生成整期目录页；
4. **合并文件**：把整期 PDF 合并；
5. **本期出刊**：按出刊规则做最后编排。
