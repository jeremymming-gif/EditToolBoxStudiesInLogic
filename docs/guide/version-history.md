# 版本记录

> **本页目录**：[去哪儿看](#去哪儿看) · [怎么读](#怎么读) · [升级提示](#升级提示)

## 去哪儿看

完整、按版本倒序的变更记录在 **[版本记录（changelog）](../reference/changelog)**，GitHub Release 页同步提供下载与说明。本页不重复抄写版本号与条目——唯一权威处就是那份 changelog。

## 怎么读

changelog 的每条按三类标记组织：

- ✨ **新增**：这一版多出来的功能与入口；
- 💎 **改进**：既有功能的行为、界面与体验变化；
- 🐞 **修复**：修掉的问题。

同一条目内先写用户能感知的变化，再写必要的边界说明；不含内部编号。

## 升级提示

- 升级前先关掉正在运行的应用；Windows 建议解压到新目录确认可用后再删旧目录。
- 设置与引用库都在本机用户目录，升级不会清掉；但**不要**把新包直接覆盖到旧包正在使用的目录。
- 想知道当前装的是哪一版：设置中心 → 高级与关于；版本号唯一出处是仓库里的 `Engine/slcn/__init__.py`。
