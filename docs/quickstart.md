# 快速上手

## 单篇稿件：从作者来稿到可编译初排稿

1. 打开 App，进入 **初排转换**；
2. 把作者源文件（`.docx` 或 `.tex`）拖到「源文件（必填）」；把输出目录拖到「输出目录（必填）」；
3. 需要时填写「正文信息覆盖」（题名、作者、单位、邮箱、摘要等）与出版信息（卷/期/年/起止页/收稿日期）；
4. 点「运行」，看下半部分运行日志；
5. 产物目录里会得到 `<作者>.tex` + `reference.bib` + 模板 `.sty`，再点「编译」即可出 PDF。

> 字段占位符、未识别字段会在日志与产物里明确标出，按提示人工补全即可。

## 参考文献核实（可选）

1. 在设置页配置你自己的 DeepSeek API（key 只存本机）；
2. 在转换页勾选「用 AI 处理参考文献」可生成《文献核实任务书》，按需打开「检索证据」；
3. 建议先在 **引用库 → 设置** 里打开 **先算账**：跑一次只打印「源 bib N / 正文引用 M / 预计检索与 AI 次数」，
   不检索、不调用 AI（零费用）；
4. 核实只针对**正文实际引用**的条目（默认上限 120，可在设置里调）；命中引用库已核实条目会**跳过**检索与 AI。

## 引用库：把核实过的参考文献沉淀下来

1. 进入 **引用库 → 库概况**，可看到条数/期数/健康状态；
2. **入藏**：选单篇 `.bib`（文献回读校验通过的那份）或整期目录，先看预览（新增/合并/冲突），确认后入库；
3. 以后核实新稿时，引擎会先查库：命中已核实条目直接复用，不再花钱检索；
4. **待裁决**：冲突与重复候选清单在笔记仓 `bib_db/CONFLICTS.md` / `DUPLICATES.md`，按清单裁决即可。

## 整期装配

- **检查tex信息** → **编译全部** → **生成目录** → **合并文件** → **本期出刊**；
- 顺序按侧边栏分组从上到下即为推荐流程。
