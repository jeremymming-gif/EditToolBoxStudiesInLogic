# 常见问题

## 这个工具会自动联网、自动花钱吗？

不会。只有你主动选择 AI 的 API 通道并确认发送，才会由本机向已配置的外部接口发请求；Chat 通道需由你把任务书交给外部对话工具。普通转换、「引用库 → AI 辅助处理 Bib」的离线体检部分和整期装配可离线使用。单篇 AI 辅助初排按任务书识别的正文引用范围准备核实条目，未引用的 Bib 条目不纳入该范围；范围不确定时会提示，不应理解为全库核实。

## AI 初排发送前会显示什么？

任务书区域显示预计委派条数和引用范围提示。条数未知或超过 120 条时，界面会阻止 Chat 复制和 API 发送。API 发送前还会显示 token 用量估算，并检查 AI 设置中的单篇和批次 token 预算。估算不是账单或金额报价；当前没有可用于此提示的价格表。
## API key 存在哪里？安全吗？

只存本机（macOS / Linux 在 `~/.editorial-toolbox/settings.json`，Windows 在 `%APPDATA%\EditToolBox\settings.json`），由外壳通过**环境变量**传给引擎，
不进命令行（`ps` / 任务管理器看不到）；不会上传到任何第三方。

## 软件设置和引用库版本操作分别在哪里？

软件设置集中在**设置中心**，分九组：外观；引擎与环境；路径；日志与诊断；高级与关于；窗口与托盘；语言与地区；AI 与模型；网络代理。界面、日志与诊断在各自组里，AI 接口、模型、密钥与 token 预算在「AI 与模型」，代理在「网络代理」。引用库自己的库位置与查库偏好在「引用库 → 引用库设置」，Git 状态与版本操作在「引用库 → 版本与同步」，都不在设置中心。

版本与同步页可查看服务提供的库状态、分支/提交信息及最近库提交，并在确认后执行支持的提交、推送或回退操作。它不提供 pull、冲突解决或自动同步；推送也不会自动发生。

## 引用库数据会传到公网吗？

引用库文件由本机配置的库路径决定。只有你主动执行相关操作时，内容才可能随 AI API 请求或 Git 推送发送到相应服务；不要将敏感数据放进未获授权的外部服务。
## 编译失败怎么办？

先看运行日志里的 xelatex/biber 报错行；最常见是没装 TeX 发行版（TeX Live / MiKTeX / MacTeX）、缺少宏包或 `.bib` 有语法问题。
转换产物与 `.log` 会保留在输出目录，便于排查。

## 能用于其他期刊吗？

默认模板、字段规范与判定规则按《逻辑学研究》体例写死；换刊需要改 `Engine/slcn/` 的规则与
`编辑笔记/模板文件/` 的模板。

## Windows 提示威胁 / macOS 打不开怎么办？

这是未签名（ad-hoc 签名）应用的正常提示：Windows **更多信息 → 仍要运行**，macOS **右键 → 打开**。
原因与接受后果见仓库 `RELEASING.md`。

## 怎么反馈问题？

到仓库 Issues 反馈：<https://github.com/jeremymming-gif/EditToolBoxStudiesInLogic/issues>。
请附版本号、系统、复现步骤与运行日志（**不要粘贴 API key**）。

## 失败了，怎么把信息发给编辑部？

反馈问题前请按顺序看四处：

1. **日志区末行**：引擎契约行（「完成。…」或「❌ 失败（退出码 N）：…」），切「只看摘要」可快速定位；
2. **结果横幅**：完成时会显示产物目录（可打开/复制），失败时显示退出码与末行；
3. **设置中心 → 引擎与环境**：九项依赖是否齐全（不联网、不读稿件内容）；
4. **设置中心 → 日志与诊断**：默认只含版本、平台、状态与错误类别；设置值、路径与日志正文需要
   **本次显式勾选**才写入。**导出为文本文件**前可先核对预览（写入文件的内容与预览逐字一致）；
   **复制诊断信息（文本）**直接复制默认最小集，不弹预览。导出前会对常见密钥形状
   （`sk-…`、`Bearer …`、`api_key=…` 等）打码，但仍请自行确认正文不含你贴入的敏感信息。

反馈时附：版本号、系统、复现步骤、上面第 1/3 步的文本（**不要粘贴 API key**）。
