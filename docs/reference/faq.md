# 常见问题

## 这个工具会自动联网、自动花钱吗？

不会。只有你**主动勾选「用 AI 处理参考文献」**、并在设置里打开「检索证据」时，才会调用外部 API；
转换、参考文献规范化、整期装配全部离线可用。核实默认只针对**正文实际引用**的条目（上限 120，可调），
引用库命中的条目会**跳过**检索与 AI。

## 「联网检索」和「检索证据」有什么区别？

- **联网检索**：让模型服务端执行内置 `web_search` 工具（Responses API）。
  `deepseek-flash` 会**静默忽略**它，只有 `deepseek-v4-pro` 真执行；费用按模型 token 计（较贵）。
- **检索证据**：直接调用 DeepSeek 独立 **Search API**，与模型无关，按**成功请求**计费（¥5/1000 次），
  结果写进《文献核实任务书》。日常核实用这一条即可。

## 想先知道这次要花多少钱？

在 **引用库 → 设置** 打开「先算账」（或命令行 `--verify-plan`），跑一次只打印核实范围与预计检索/AI 次数，
不检索、不调用 AI、零费用。

## API key 存在哪里？安全吗？

只存本机（macOS 在应用支持目录的 `ai.json`，Windows 在 `%APPDATA%\EditToolBox\settings.json`），由外壳通过**环境变量**传给引擎，
不进命令行（`ps` / 任务管理器看不到）；不会上传到任何第三方。

## 引用库在哪里？会不会把数据传到公网？

引用库放在**私有笔记仓**的 `bib_db/`，只在本机；公开仓库与 Release 里**不含**引用库数据、作者稿件或密钥。

## 一次 AI 核实会花多少钱？

默认只核**正文实际引用**的条目（上限 120、可调），不会被作者 `.bib` 里未引用的条目拖出费用；
命中引用库已核实条目直接跳过检索与 AI。想先看账，可在「引用库 → 设置」打开**先算账**做零费用预览，
或用 `--verify-plan` 只打印范围与预计次数。

## 编译失败怎么办？

先看运行日志里的 xelatex/biber 报错行；最常见是没装 TeX 发行版（TeX Live / MiKTeX / MacTeX）、缺少宏包或 `.bib` 有语法问题。
转换产物与 `.log` 会保留在输出目录，便于排查。

## 能用于其他期刊吗？

默认模板、字段规范与判定规则按《逻辑学研究》体例写死；换刊需要改 `Engine/slcn/` 的规则与
`编辑笔记/模板文件/` 的模板。

## Windows 提示威胁 / macOS 打不开怎么办？

这是未签名（ad-hoc 签名）应用的正常提示：Windows **更多信息 → 仍要运行**，macOS **右键 → 打开**。
原因与接受后果见仓库 `RELEASING.md`。

## 怎么反馈问题？

到仓库 Issues 反馈：<https://github.com/jeremymming-gif/EditToolBoxStudiesInLogic/issues>。
请附版本号、系统、复现步骤与运行日志（**不要粘贴 API key**）。

## 失败了，诊断卡上的「类别」是什么意思？

诊断卡把这次失败归到 17 类之一（如缺模板、TeX 报错、biber 失败、权限、文件被占用、磁盘满、被取消），
并给 2–4 条下一步；证据是脱敏后的日志尾部。点「打开日志」看完整原始行，点「复制诊断包」把本地纯文本
（≤16KB、零上传、不含正文/bib）贴给编辑部。旧版引擎没有诊断器时会自动回退为「退出码 + 日志尾部」。
