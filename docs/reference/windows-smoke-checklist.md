# Windows 真机冒烟清单

> **状态：待 Win11 真机回执。** 桥接测试（`sources-win/tests/test_bridge.py`，含真开窗口的 (g)(h) 组）
> 能在 macOS/Linux 上跑，但**控件外观、中文输入、目录拖拽、字体与 PyInstaller 打包**只有
> Windows 真机才测得到 → 每次发版前在 Win11 上按本清单走一遍，把「回执」列填满。
> 本清单替代「发版前各做一次真机冒烟」里 Windows 那一半（macOS 侧按 `Engine/docs/DELIVERY-CHECKLIST.md`）。

## 前置

- Windows 11 22H2+；**不装 Python**（模拟用户机器：`编辑部工具箱.exe` 与 `SLCNEngine.exe` 放在同一目录）。
- 准备沙盒：把一份真实期目录**复制**到 `%USERPROFILE%\Desktop\冒烟期`，全程只在副本上试清理，
  真实期目录（`20xx年第N期(…)`）只读。
- 版本记录：发布包版本号（设置页/关于处可见）+ 本清单文件在仓库的提交号。

## 清单

| # | 项 | 操作 | 期望 | 失败报什么 |
|---|---|---|---|---|
| 1 | 启动与版本 | 双击 `编辑部工具箱.exe` | 主窗口起来，侧栏三组 + 设置；设置页显示引擎路径（指向旁边 `SLCNEngine.exe`）；无控制台黑框 | 版本号、窗口标题、设置页引擎状态原文、是否弹出错误框（截图） |
| 2 | 初排转换 | 选一份 `.docx` 来稿 + 输出目录 → 运行 | 日志**实时**逐行刷新；末行 `完成。初排转换…`；产出 `.tex` / `.pdf`（勾了编译时）；源稿未被改动 | 「原始」层日志文件、源稿与输出目录 `dir /b` 结果、退出码 |
| 3 | 文献回读校验 | 选改回后的 `.bib` → 运行（再试一次「并回」） | 体检报告可读；并回产物 `reference.bib` 生成、旧文件先备份 `.ai前`；退出码 1 = 有命中项（不是失败） | 报告路径、退出码、`.bib` 首 20 行（脱敏后） |
| 4 | 一校核查 | 选初排稿 `.tex` → 运行 | 命中清单按规则列出、可打开报告；默认只报不改（原稿字节不变） | 报告路径、退出码、命中条数 |
| 5 | 清理·编译临时文件（默认） | 清理页选沙盒期目录；先**勾着**「先预演」运行；再取消勾选运行并在确认框点「移入回收目录」 | 预演只列清单、一个文件不动；真跑确认框列出**具体清单与大小**；结束后 `.aux` 等移走、`.tex/.pdf/.sty/.bib/.log` 仍在、`original/` 未进、出现 `.toolbox-trash\<目录名>-<时间戳>\` | 确认框截图、日志末 20 行、「原始」层全文、`dir /b`（含 `.toolbox-trash`） |
| 6 | 撤销清理 | 接第 5 项：横幅上点「撤销清理」 | 文件原样搬回；契约行 `完成。已恢复 N 个文件（目录：…）`；回收目录留在原处（不自动删） | 日志原文、撤销前后同一文件 sha256（`certutil -hashfile <文件> SHA256`） |
| 7 | 清理·交付收尾（白名单） | 模式选「交付收尾（白名单）」运行 | 保留白名单与 tex 引用闭包、`original/`、人工交付清单；引用缺失时期目录显示退出码 2 且**一个文件都没动**（日志写明引用缺失） | 日志末 20 行、缺失引用的文件名、跑前跑后 `dir /b` 对比 |
| 8 | 清理·工作区旧件 | 模式选「工作区旧件（每期留最新合并 PDF）」运行 | 每期多份 `合并*.pdf` 只留文件名时间最新一份；固定名 `合并.pdf` 永不删；解析不出时间时保守保留 | 日志里保留/移走的文件名清单 |
| 9 | 清空回收站（永久） | 先做第 5 项产生回收目录 → 点「清空回收站…」→ 读确认框 → 点「永久清空」 | 确认框写明**永久删除、不可撤销、清空后无法恢复**；成功契约行 `完成。已清空回收站 N 个回收目录（目录：…）`；**期目录里 `.toolbox-trash\` 目录本身消失**（资源管理器里看不到）；成功后横幅**没有**「撤销清理」 | 确认框截图、清空前后 `dir /a /b`（含隐藏项）、日志末 5 行 |
| 10 | 编译全部 | 选期目录 → 运行 | 每篇 `XeLaTeX → biber → XeLaTeX×2` 逐篇出日志；某篇失败只停那一篇；末行计数与 `.log` 位置 | 失败篇目名、该篇 `.log` 里 `!` 起始的 10 行、退出码 |
| 11 | 生成目录 | 先跑「检查tex信息」拿报告，再选「生成目录」 | macOS 顺序为 查→编→目录；**Windows 版「生成目录」在「编译全部」之前**（侧栏顺序如此）；生成中外文目录 tex（勾落位/编译后落固定名并出 PDF） | 信息检查报告路径、生成的两份 tex/PDF 路径、「原始」层日志 |
| 12 | 合并文件 | 选期目录 → 运行 | 输出 `合并<时间戳>.pdf`；书签层级/编委页/封底按开关生效；可打开产物 | 产物路径与页数、书签截图、日志末 10 行 |
| 13 | 引用库 5 页 | 依次点「库概况 / 查库 / 入藏 / 待裁决 / 引用库设置」 | 库概况有计数；查库能按 key/DOI/题名查、可复制 BibTeX；入藏先 dry-run 再确认；**「待裁决」可逐条 keep/adopt/defer，写库成功后只对库文件本地 commit（不推送；无 git 时只黄字提示）**（mac 叫「待处理」）；设置页开关能保存 | 每页截图、库文件路径、`git log --oneline -3`、退出码 |
| 14 | 日志复制 / 停止 | 跑一个较长任务（编译全部）→ 点「停止」；再跑一次，切「原始」层、点「复制」 | 停止能停整棵进程树（不留 xelatex 残留，任务管理器确认）；摘要/原始可切、复制内容完整、可保存为文件 | 进程管理器截图（是否残留 xelatex）、复制出的日志文件 |
| 15 | 设置与重启 | 设置页改「引擎目录」保存 → 关闭再开 | 重启后仍生效；密钥打码显示、只落本机 | 设置页截图（打码后）、`%APPDATA%` 下配置文件路径 |
