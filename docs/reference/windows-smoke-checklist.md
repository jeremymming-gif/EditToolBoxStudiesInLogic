# Windows 真机冒烟清单

> **状态：待 Win11 真机回执。** 自动化只能覆盖 pytest（不启动 GUI）、引擎套件与 sidecar 自检；
> **外观、中文输入、原生对话框、系统拖放降级、托盘/标题栏、PyInstaller 打包**只有 Windows 真机才测得到 →
> 每次发版前在 Win11 上按本清单走一遍，把「回执」列填满（缺回执不得发版）。
> macOS 侧按同一清单走一遍（文件名/App 名不同），并在回执里注明平台。

## 前置

- Windows 11 22H2+；**不装 Python**（模拟用户机器：`编辑部工具箱.exe` 与 `SLCNEngine.exe` 放在同一目录）。
- 准备沙盒：把一份真实期目录**复制**到 `%USERPROFILE%\Desktop\冒烟期`，全程只在副本上试清理，
  真实期目录只读。
- 版本记录：发布包版本号（「设置 → 关于与诊断」或「帮助与关于」可见）+ 本清单文件在仓库的提交号。

## 失败信息冒烟

1. 初排转换一个坏输入（空文件/缺模板）→ 结果横幅给出可读原因与建议，日志尾部保留原始输出。
2. 一校核查一篇有命中的稿 → 退出码 1 显示为**中性**（不是「失败」），横幅文案可读。
3. 设置 → 环境检查：在缺 TeX 的环境下应把对应项标红并给安装提示，其余项照常（检查只读、不阻断）。
4. 运行中关闭窗口 → 先落盘设置再退出，无残留进程（任务管理器确认）。
5. 断网执行以上步骤：全部仍可用（除依赖网络的功能外），诊断不联网。
记录：通过/失败 + 截图或文字回执；无 Win11 真机时在回执里写 SKIP 并说明原因。
