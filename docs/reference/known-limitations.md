# 已知限制与绕行

适用版本：**v1.4.1**（2026-10-28 发布）；只列当前版本仍存在的限制，已修复项不入表。
本页随版本维护，与 GitHub Release 正文「已知问题」同源。

| 限制 | 症状 | 影响 | 绕行 | 目标版本 |
|---|---|---|---|---|
| 个别案例附录字号（86-05） | 引擎按默认字号排版；人工附录为 9pt，该稿 28 页 vs 人工 26 页 | 个别案例的版式差，不算缺陷 | 需要 9pt 时在 tex 附录前用 `\zihao{-5}`，全文末用 `\zihao{5}` 复位 | 无（体例项；可选开关待编辑部确认） |
| 验收判据与人工口径差异 | 3 项验收口径差异：86-10 判据误报；88-01/88-02 注内引用 `\parencite` 与人工 page-locator 不同 | 验收报告出现错误的优先级归类 | 按报告中的归因说明阅读；不改判据（不对单条加严） | 待编辑部拍板（改判据需另走版本） |
| 参考文献源清单计数误报 | 源清单覆盖/引用计数类误报（如标题 `\textup{}`、引号归一化） | 仅报告噪声；产物 bib 齐全 | 该噪声已在开发主线修复（2026-10-29），将随下一版本发布；v1.4.1 发行版仍会看到，忽略该 finding、以 bib 条目与人工核对为准 | 下一版本（开发主线已修复） |
| Word 英文标题页 | 英文稿标题页版式与人工版有差异 | 轻微版式差异，信息项 | 人工后期微调；不视为缺陷 | 待专项（优先级低） |
| Windows 平台覆盖 | 真机冒烟只在发版前各做一次 | 平台长尾风险 | 每次发版前对 Windows/macOS 各做一次真机冒烟（Windows 按 `docs/reference/windows-smoke-checklist.md` 逐项走、留回执）；桥接测试常跑 | 发版流程固定项 |
| LibreOffice 条件必需 | 未安装时合并 PDF / 导出原稿 PDF 降级并给出 warning | 仅这两个功能；初排转换不受影响 | 安装 LibreOffice，或按 CLI 提示路径处理 | 无（已文档化） |
| 模板/连接号默认行为变化 | 与 1.4.0 产物不同（ZH-08 默认启用、模板 88 版式） | 交付稿版式变化 | 如需 1.4.0 旧行为，可用既有开关回退 | 无（预期行为） |
| 目录生成字体检查 | `fontset=windows` 前置检查会因缺字体中止（设计如此） | 无字体环境不能生成目录 | 安装字体，或按提示处理 | 无 |
| 大期合并内存 | 整期合并 PDF 大文件时内存占用高（历史观察） | 极端期可能较慢 | 分批合并，或加大内存 | 待观察 |

## 反馈与更新

发现未列入的限制、或绕行办法不适用：请到 GitHub Issues 反馈（附版本号与复现步骤）。
本页随版本更新；历史版本的「已知问题」以对应 Release 正文为准。

## 失败诊断的边界

- 只诊断**五页**（初排转换 / 一校核查 / 信息检查 / 编译全部 / 参考文献规范化），其余页仍只显示退出码。
- 诊断靠日志关键字，归不了类时给 `unknown` 低置信，不硬猜；卡片仍会显示日志尾部。
- 诊断器只读日志尾部 16KB；更早的旧行不参与分类。
- 旧版引擎或缺 `diagnose.py` 时回退为「退出码 + 日志尾部」，不阻断运行。
- 诊断包零上传；不要把整份稿件贴进反馈，只贴脱敏诊断包与必要日志。
