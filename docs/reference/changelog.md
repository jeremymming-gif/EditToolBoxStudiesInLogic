## 未发布（2026-10-20，第 52–61 批）

- **引用库命中二次判定 / 写法归一（第 61 批，2026-10-20）**：新增 `hit=title-normalized`（题名写法归一后
  ≥0.98 + 年/作者/出版社至少再一条见证，任一见证矛盾即否决）与 `hit=content-identical`（与库内 verified
  记录逐字段内容指纹完全相同）；两条仍只跳过检索/AI 与任务书核实、**不改产物**；`query_title` 不放宽。
  复测：5 期 35 篇成品 1576 条 safe 98.92%→99.87%、候选 17→2；全库 84 篇 3779 条 97.80%→99.23%、
  候选 67→13、未命中 16（更早期次、库内确无）；初排 8 篇 183 条 93.44%→96.72%、候选 8→3。
  无 false-safe（11 条反例 0、oracle 抽样通过、REGRESS=0）；转换产物（`.tex`/`reference.bib`）零变化
  （命中只影响跳过检索/AI、任务书「五、库内已核实」与日志计数）。
- **全文 AI 核查通道②：直连 API（第 60 批，2026-10-20，可选、默认关）**：`--llm-fulltext` 只配合
  `--verify-refs` 的 ⑪ 直连路径，把正文按 ≤3 万字符/片发给配置端点（每片一次请求、**会产生费用**）；
  **report-only**：只生成 `<名>_AI全文复核.md`（逐条建议/分片/拒绝，不落正文全文），不改
  `reference.bib`/`.tex`，**自动应用未实现**（留用户拍板）。预算闸按「片数×(字数/3+输出上限)」预估，
  超限或未配置端点 → 退出 2 且零请求（默认单篇预算 30000 通常不够，需调大）；单片超时/HTTP 错/截断/
  JSON 不过 → 标「AI 建议不可用」继续出稿；两壳初排页 AI 区加默认不勾的复选框（会话态）。
- **全文 AI 核查通道①（第 59 批，2026-10-20，可选、默认关）**：两段式初排可加 `--coop-fulltext {context,full}`，
  任务书在「附二」后多「附三、正文全文/引用上下文」——`context` = 引用/脚注锚点前后各 300 字窗口合并
  （上限 4 万字符≈13k tokens），`full` = 正文全文（上限 8 万字符≈27k tokens），超限显式截断；只写本机任务书，
  由编辑自己复制给外部 chat（软件零上传、零费用），复用原回复契约与 `--coop-apply`，不新增改正文类建议；
  默认不加时任务书/产物/stdout 与批 58 逐字节相同；两壳两段式面板加默认不勾的复选框 + 范围单选 + 隐私提示。
  ⚠ 当时直连 API 全文核查（通道②）尚未实现；第 60 批已补（见上）。
- **初排默认只读引用库比对 + 安全命中增强 + Mac 默认任务书（第 58 批，2026-10-20）**：初排不传
  `--verify-refs` 也会只读比对编辑部引用库，日志多一行「引用库比对：命中 X / 候选 Y / 未命中 Z
  （只读，不改产物）」；新增 `--no-bibdb-verify` 关闭（无库/无 bib 静默；`.tex`/`reference.bib`/任务书/argv
  与从前相同）。引用库安全命中补「译著/CJK 作者责任标记」规则（题名≥0.98+年+出版社+标记归一相容；
  命中仍只跳过检索/AI、不改稿；84 篇成品 bib 计数不变，Bo_Chen 初排 safe 84%→96%、候选 4→1）。
  macOS「生成参考文献核实任务书」改为默认勾选、对齐 Windows（会话态、无持久化）。
- **低置信建议三类应用（第 57 批）**：`--coop-apply` 从「只应用文献字段」扩展为三类——
  ① `BIB-*` → `reference.bib`（沿用四条安全校验）；② `META-*` → 输出 `.tex` 的 `\my*` 元数据
  （只填空/模板占位，编辑侧已有值不覆盖，值过格式校验）；③ `FN-*` 窄口径：仅 `citation_unmatched`
  纯引用脚注按回填的 `match_key`（键须在任务书与当前 bib 内）提升为正文 `\parencite[loc]{key}`
  （原文含页码线索必须给 `locator`）。有写入才备份 `<名>.tex.ai前`（与 `reference.bib.ai前` 同构，
  进最终交付目录、`--clean` 不删、可恢复）；其余建议只列清单待人工。无新 CLI 参数，
  状态 schema 1 / `stats` 7 键不变，GUI 仅文案同步。
- **C 类新口径默认开启**：Word 稿脚注文献按四类处理——纯引用脚注 → 正文 `\parencite[页码]{键}`
  （删脚注）；完整文献条目型并入并集参考文献；混合型保留脚注并出「请人工核对」warning；
  纯说明脚注原样。参考文献 = 脚注引注 ∪ 文末清单，按（作者 + 题名 + 年份 + 类型）去重，
  同作品仅页码不同合并 1 条。匹配不到完整条目的纯引用不编造（保留脚注 + warning）。
  命令行 `--no-c-class-union` 可回退旧行为；GUI 无开关，默认即新口径。
- **AI 协同初排（两段式，第 54–56 批）**：外部 chat 免费流程——第一段 `--coop-taskbook-only` 只写暂存目录
  `<输出目录>/<名_姓>_待核/` + 《AI 核实任务书》（含「附一、初排低置信项」），编辑把任务书交给自己的 chat
  模型并回填；第二段 `--coop-replies` 校验指纹后并入文献字段、出低置信建议，`--coop-apply` 才改
  `reference.bib`（先备份 `.ai前`；第 54–56 批只应用文献字段，第 57 批扩展为三类，见上），最后编译并原子交付、
  生成 `_AI协同记录.md`。软件本身不上传内容、不调用 API、零费用；直连 API 通道另有 token 预算闸。
- **GUI 接入两段式（第 55–56 批，macOS + Windows 对等）**：「初排转换」页新增默认关闭的
  「AI 协同初排（两段式；外部 chat 免费流程）」勾选与状态区——第一段后「待人工核实（未交付）」，
  可打开任务书 / 暂存目录、把回填加进「已选清单」（多文件 / 目录 / 剪贴板，可移除 / 全部清除）、
  勾「一键修改产物（--coop-apply；默认不勾）」、运行第二段；成功后「已交付」，显示交付目录 / 协同记录 /
  建议清单与摘要，失败显示退出码 + 日志尾部。第 56 批起两壳都是「先加回填清单、再运行第二段」；
  Windows 按钮为「添加回填文件…／添加回填目录…／从剪贴板导入」「运行第二段…」。
- **回填体验修复（第 56 批）**：`--coop-replies` **可重复**（chat 把 JSON 与 BibTeX 拆成两个文件时
  一块传一个；同一真实路径去重，单路径行为不变）；任务书新增「附二、回填说明」并把第三节第 10 条限定为
  「文献条目部分」（附一 JSON 单独回复，非协同任务书逐字节不变）；第二段支持 `--clean`（编译后清
  `.aux/.bbl/.bcf/.blg/.out/.run.xml` 再交付，`.log` 保留）；状态 JSON 增 `stats`（7 键，旧状态向后兼容）；
  成功摘要统一为「文献回填 x/y（并入 z 条，未回填 n）｜低置信回复 a（应用 b / 仅记录待人工 c）」，
  **文献回填 0 条时橙色警告**（可能漏导入 bibtex/bib），不再出现误导性的「待人工 0」。
- **AI 预算设置（第 55 批）**：「设置」页新增「单篇预算 / 单批预算」（默认 30000 / 1000000，0 = 不限，
  留空 = 不传），只约束直连 API 通道；外部 chat 两段式零费用不生效，隐私文案同步写明零上传。
  口径提醒：建议清单第二段跑完才生成；`--coop-apply` 须在运行第二段前决定（phase=done 后重跑幂等早退）；
  GUI 未做任务书自动分片；回填要两部分都交。不加协同开关时旧行为逐字节不变。
