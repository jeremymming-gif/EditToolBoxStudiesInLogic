# 版本记录

当前稳定版本：**1.2.1**（macOS + Windows）。

完整变更以 GitHub Releases 为准：<https://github.com/jeremymming-gif/EditToolBoxStudiesInLogic/releases>

## 1.2.1（2026-10-18）

- **Word 通道实例修复（期 87 / 期 90）**：公式里的中文包 `\text{}`（不再 `Missing character` / 乱码）；
  参考文献解析补强（引号题名、APA 整条、非数字期号与字母页码、混合编号清单、脚注文献不再整条丢失）；
  LogicA 私有符号映射（`→ ∈ ∅ ∞ ⟨ ⟩` 等不再静默消失，`∞-群胚` 一类恢复）；
  英文人名顺序（`GAO Bei-bei` → `Beibei Gao`）。
- **一校核查 / 文献回读校验体检**：26 条一校规则对初排稿逐条离线核查；回读校验把「bib 有、正文没引用」
  等不闭合情形明确报出；两条链路都补了真实稿的回归夹具。
- **官网**：安装说明改为 **Windows 优先**（Windows 解压即用、两个 exe 放同一文件夹、SmartScreen 说明在前），
  同时修正 macOS 首次打开说明。
- **基线**：全库 Word 源稿体例普查（`docx_audit`）按新解析口径重冻结，变坏迁移为 0。

## 1.2.0（2026-10-18）

- **编辑部引用库**：已核实 bib 沉淀入库；核实前先查库、命中即跳过重复检索与 AI（省时省钱）。
  macOS / Windows 新增「引用库」5 页：库概况 / 查库 / 入藏 / 待裁决 / 引用库设置（两平台合计各 15 页）。
- **参考文献核实成本闸门**：只核正文实际引用、上限可调、先算账预览；引用库命中不花钱。
- **引用库治理**：冲突裁决（keep / defer / adopt）持久化与 AI 辅助裁决；B1 规范化 dry-run / apply；
  B2 英文作者倒装；B3 编者倒装 dry-run。写库一律先备份并校验指纹。
- **初排与构建**：LaTeX 旧版模板 `.sty` 定理环境迁移、本地定义缺失预检、附件选择与「真 `.bib` 优先」修复；
  `corpus.py` 并行回归（69 篇约 10 分钟 → 约 4 分钟）与 R5 确定性修复（同输入连跑两遍逐字节一致）。
- **界面**：GUI 拖拽与路径输入修复；运行中可取消、日志分「摘要 / 原始」两层（两平台语义一致）。
- **项目治理**：案例库索引 / 分类 / DIGEST 与案例库体检、`selfcheck.py` 一键自查上线。
