# 版本记录

当前稳定版本：**1.1.1**（macOS + Windows）。

完整变更以 GitHub Releases 为准：<https://github.com/jeremymming-gif/EditToolBoxStudiesInLogic/releases>

## 1.1.1

- 初排转换、文献回读校验、一校核查、合并文件、整期装配全流程可用（macOS + Windows 双外壳）；
- 参考文献核实支持 DeepSeek Search API「检索证据」与 Responses 内置检索（按模型区分能力）；
- 引言/正文迁移、旧版模板与本地 `.sty` 定义按差集迁移、编译前定义缺失提示；
- 新增**编辑部引用库**：已核实 bib 入库，核实前先查库命中即跳过检索与 AI；
- 新增**核实成本闸门**：只核正文引用、上限可调、先算账、模型能力前置提示；
- 文档与项目主页（本站）上线。
