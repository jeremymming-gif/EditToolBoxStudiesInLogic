# 版本记录

当前稳定版本：**1.3.0**（macOS + Windows）。

完整变更以 GitHub Releases 为准：<https://github.com/jeremymming-gif/EditToolBoxStudiesInLogic/releases>

## 1.3.0（2026-10-21，第 65–71 批）

- **整期出刊真正一键跑完一期（第 71 批）**：「本期出刊」改为**五步**——检查 tex 信息 → 生成目录 →
  编译全部 → **目录 PDF 自动编译并放入 `000` 目录** → 合并整期 PDF；合并默认与「合并文件」页三开关
  一致（嵌套书签 / 编委页 / 封底），不需要时可 `--no-*` 关闭；该期没有 `000` 目录时可用 `--skip-toc-pdf` 跳过。
  真实第 90 期只读副本实测：与人工合并 PDF **176/176 页、102/102 书签、大纲 diff 0**。
- **Word 通道文献与作者信息（第 68/70/71 批）**：自动编号文献清单物化进 bib（安全闸不满足时只 warning，
  不猜）；同段多文献 / 译著拆条 / 中文条目切分修复；脚注引文 ↔ 文末条目**同作品去重** + 未链文末条目 warning；
  作者信息 / 作者简介 / 收稿日期 / 基金项目从 `footnotes.xml` 抽取填元数据（**只填不覆盖、不猜**）。
- **引用库健康门禁（第 71 批）**：新增 `bibdb.py rehash`（默认 dry-run，`--apply` 才原子写）；真实库 lint
  error 6 → 0；「库概况」页在库有 error 时直接显示可操作的修复命令。
- **验收口径改为基线无关 L1–L4（第 71 批）**：复测不再以最终人工成品为基线；与人工成品的差异只做三分类
  归因（软件缺陷 / 源稿本身问题 / 人工后期修改），页数差、版式差降为信息项；旧口径 `--legacy-final` 可复现。
- **macOS App 版本标识（第 71 批）**：设置页显示 `1.3.0+<commit> (构建时间)`；构建时工作树有未提交改动
  标 `-dirty`，发版 tag 构建为 clean 态 —— 不再有「显示 1.2.2 实际含发布后代码」的歧义。
- **其它（第 67/69 批）**：初排页元数据入口收敛为表单单一入口；「第一作者」→ 元数据表单第一作者中文姓名
  单向预填；P0 判据收口（页数差降 P1）；测试 hermetic 化（不再依赖 `/tmp` 真稿 gate）。

> 已知限制与详细说明以 GitHub Release `v1.3.0` 正文为准。
