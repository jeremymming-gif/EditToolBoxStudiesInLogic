# 版本记录

当前稳定版本：**1.2.1**（macOS + Windows）。

完整变更以 GitHub Releases 为准：<https://github.com/jeremymming-gif/EditToolBoxStudiesInLogic/releases>

## 未发布（2026-10-19，第 52–55 批）

- **C 类新口径默认开启**：Word 稿脚注文献按四类处理——纯引用脚注 → 正文 `\parencite[页码]{键}`
  （删脚注）；完整文献条目型并入并集参考文献；混合型保留脚注并出「请人工核对」warning；
  纯说明脚注原样。参考文献 = 脚注引注 ∪ 文末清单，按（作者 + 题名 + 年份 + 类型）去重，
  同作品仅页码不同合并 1 条。匹配不到完整条目的纯引用不编造（保留脚注 + warning）。
  命令行 `--no-c-class-union` 可回退旧行为；GUI 无开关，默认即新口径。
- **AI 协同初排（两段式，第 54–55 批）**：外部 chat 免费流程——第一段 `--coop-taskbook-only` 只写暂存目录
  `<输出目录>/<名_姓>_待核/` + 《AI 核实任务书》（含「初排低置信项」），编辑把任务书交给自己的 chat 模型
  并回填；第二段 `--coop-replies` 校验指纹后并入文献字段、出低置信建议，`--coop-apply` 才改
  `reference.bib`（先备份 `.ai前`，只应用文献字段；FN/META/BIB-LINE 只列建议待人工），最后编译并原子交付、
  生成 `_AI协同记录.md`。软件本身不上传内容、不调用 API、零费用；直连 API 通道另有 token 预算闸。
- **GUI 接入两段式（第 55 批，macOS + Windows 对等）**：「初排转换」页新增默认关闭的
  「AI 协同初排（两段式；外部 chat 免费流程）」勾选与状态区——第一段后「待人工核实（未交付）」，
  可打开任务书 / 暂存目录、导入 AI 回复、勾「一键修改产物（--coop-apply；默认不勾）」、运行第二段；
  成功后「已交付」，显示交付目录 / 协同记录 / 建议摘要，失败显示退出码 + 日志尾部。
  两壳按钮文字略有差异（Windows 为「导入 AI 回复并运行第二段…」，导入支持多选文件 / 目录）。
- **AI 预算设置（第 55 批）**：「设置」页新增「单篇预算 / 单批预算」（默认 30000 / 1000000，0 = 不限，
  留空 = 不传），只约束直连 API 通道；外部 chat 两段式零费用不生效，隐私文案同步写明零上传。
  口径提醒：建议清单第二段跑完才生成；`--coop-apply` 须在第二段前决定（phase=done 后重跑幂等早退）；
  GUI 未做任务书自动分片。不加协同开关时旧行为逐字节不变。

## 1.2.1（2026-10-18）

- **Word 通道实例修复（期 87 / 期 90）**：公式里的中文包 `\text{}`（不再 `Missing character` / 乱码）；
  参考文献解析补强（引号题名、APA 整条、非数字期号与字母页码、混合编号清单、脚注文献不再整条丢失）；
  LogicA 私有符号映射（`→ ∈ ∅ ∞ ⟨ ⟩` 等不再静默消失，`∞-群胚` 一类恢复）；
  英文人名顺序（`GAO Bei-bei` → `Beibei Gao`）。
- **一校核查 / 文献回读校验体检**：26 条一校规则对初排稿逐条离线核查；回读校验把「bib 有、正文没引用」
  等不闭合情形明确报出；两条链路都补了真实稿的回归夹具。
- **官网**：安装说明改为 **Windows 优先**（Windows 解压即用、两个 exe 放同一文件夹、SmartScreen 说明在前），
  同时修正 macOS 首次打开说明。
- **基线**：全库 Word 源稿体例普查（`docx_audit`）按新解析口径重冻结，变坏迁移为 0。

## 1.2.0（2026-10-18）

- **编辑部引用库**：已核实 bib 沉淀入库；核实前先查库、命中即跳过重复检索与 AI（省时省钱）。
  macOS / Windows 新增「引用库」5 页：库概况 / 查库 / 入藏 / 待裁决 / 引用库设置（两平台合计各 15 页）。
- **参考文献核实成本闸门**：只核正文实际引用、上限可调、先算账预览；引用库命中不花钱。
- **引用库治理**：冲突裁决（keep / defer / adopt）持久化与 AI 辅助裁决；B1 规范化 dry-run / apply；
  B2 英文作者倒装；B3 编者倒装 dry-run。写库一律先备份并校验指纹。
- **初排与构建**：LaTeX 旧版模板 `.sty` 定理环境迁移、本地定义缺失预检、附件选择与「真 `.bib` 优先」修复；
  `corpus.py` 并行回归（69 篇约 10 分钟 → 约 4 分钟）与 R5 确定性修复（同输入连跑两遍逐字节一致）。
- **界面**：GUI 拖拽与路径输入修复；运行中可取消、日志分「摘要 / 原始」两层（两平台语义一致）。
- **项目治理**：案例库索引 / 分类 / DIGEST 与案例库体检、`selfcheck.py` 一键自查上线。
