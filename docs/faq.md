# 常见问题（FAQ）

### 这个工具会自动联网、自动花钱吗？

不会。只有你**主动勾选「用 AI 处理参考文献」**、并在设置里打开「检索证据」时，才会调用外部 API；
转换、回读校验、整期装配全部离线可用。核实默认只针对**正文实际引用**的条目（上限 120，可调），
引用库命中的条目会**跳过**检索与 AI。

### 「联网检索」和「检索证据」有什么区别？

- **联网检索**：让模型服务端执行内置 `web_search` 工具（Responses API）。`deepseek-flash` 会**静默忽略**它，
  只有 `deepseek-v4-pro` 真执行；费用按模型 token 计（较贵）。
- **检索证据**：直接调用 DeepSeek 独立 **Search API**，与模型无关，按**成功请求**计费（¥5/1000 次），
  结果写进《文献核实任务书》。日常核实用这一条即可。

### 想先知道这次要花多少钱？

在 **引用库 → 设置** 打开「先算账」（或命令行 `--verify-plan`），跑一次只打印核实范围与预计检索/AI 次数，
不检索、不调用 AI、零费用。

### API key 存在哪里？安全吗？

只存本机（macOS 在 `~/Library/Application Support/cn.edu.sysu.logic.toolbox/ai.json`，Windows 在本地配置目录），
由外壳通过**环境变量**传给引擎，不进命令行（`ps` 看不到）；不会上传到任何第三方。

### 引用库在哪里？会不会把数据传到公网？

引用库放在**私有笔记仓** `EditToolBox-notes/bib_db/`，只在本机；公开仓与 Release 里**不含**引用库数据、
作者稿件或密钥。

### 为什么以前一次 AI 核实花了很多钱？

旧版会把作者整份 `.bib`（可能几百条）都送去核实。现在默认只核**正文引用**的条目，且有上限与先算账；
命中引用库已核实条目直接跳过。作者 `.bib` 里未引用的条目不会再产生费用。

### 编译失败怎么办？

先看运行日志里的 xelatex/biber 报错行；最常见是没装 TeX Live、缺少宏包或参考文献 `.bib` 有语法问题。
转换产物与 `.log` 都会保留在输出目录，便于排查。

### 能用于其他期刊吗？

默认模板、字段规范与判据按《逻辑学研究》体例写死；换刊需要改 `Engine/slcn/` 下的规则与
`编辑笔记/模板文件/` 下的模板。

### macOS 打不开 / Windows 提示威胁怎么办？

这是未签名（ad-hoc 签名）应用的正常提示：macOS **右键 → 打开**，Windows **更多信息 → 仍要运行**。
原因与接受后果见 `RELEASING.md`。
