# 旧版双壳使用说明（归档）

> **仅作历史参考。** 当前版本是 Flet 单壳，界面与操作顺序见[快速上手](/guide/quickstart)。
> 本页描述的两套旧外壳（macOS SwiftUI / Windows Tkinter）自 v1.5.0 起已移除，源码可按 MIT 从
> `v1.5.0` 标签取回。

## 当时的样子

- **两套外壳、两套页面**：macOS 与 Windows 各有一套界面，功能对齐、页面同名但实现不同；
  两边的页面总数均为 15 页。
- **导航按流程分组**：单篇稿件（选稿 → 初排 → 参考文献核对 → 一校核查）、整期装配（检查 → 目录 →
  编译 → 合并 → 清理）、引用库（概况 / 查库 / 入藏 / 待裁决 / 引用库设置）、以及设置与诊断。
- **诊断卡 / 诊断包**：首启自动弹环境检查，失败时可导出诊断包随 issue 附上。
- **系统拖放**：窗口接收从资源管理器 / 访达拖入的稿件。

## 与当前版本的差异（只列会影响操作的）

| 旧版（双壳） | 当前（Flet 单壳） |
|---|---|
| 两套界面，macOS / Windows 页面分别维护 | 同一套界面，两平台一致 |
| 单篇稿件四步（含参考文献核对独立页） | 单篇稿件三步；参考文献核对并入「参考文献规范化」步骤 |
| 引用库 6 个页面，Windows 叫「待裁决」 | 引用库 9 个视图，统一叫「待处理」 |
| 首启自动检查 + 诊断卡 / 诊断包 | 在「设置 → 环境检查」手动运行；诊断卡 / 诊断包未提供 |
| 可把文件直接拖进窗口 | 不接收系统拖放，用「浏览…」选文件 |
| 整期装配 5 步（无目录摘要推送） | 整期装配 6 步（新增目录摘要推送） |

旧版的命令与路径写法（`python3`、`/tmp`、`/opt/homebrew` 等）也不再是当前的推荐口径；
当前平台命令见 [安装](/guide/install) 与 [快速上手](/guide/quickstart)。
