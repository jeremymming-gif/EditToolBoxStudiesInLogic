# 设置中心

> **本页目录**：[一句话定位](#一句话定位) · [入口](#入口) · [前提](#前提) · [操作步骤](#操作步骤) · [示例](#示例) · [限制与已知问题](#限制与已知问题)

## 一句话定位

「设置中心」把散落的选项收成**九组**：外观、引擎与环境、路径、日志与诊断、高级与关于、窗口与托盘、语言与地区、AI 与模型、网络代理。左边选组，右边改值；改完即时生效，不需要重启。

## 入口

三种等价入口：

- 左侧导航 **系统 → 设置**，再点组名；
- 快捷键 `Ctrl+,`（macOS `⌘,`）；
- 顶部[命令面板](./search)（`⌘K` / `Ctrl+K`）里搜「设置」。

引用库自己的「引用库设置」在引用库导航里，不在设置中心。

## 前提

- **无需联网**：除「AI 与模型」里的连接测试外，其余设置都在本机生效。
- **写入位置**：本机用户配置目录；卸载应用不会删除设置文件，重装后仍生效。
- **管理员权限**：改路径到系统目录时才需要；一般不需要。

## 操作步骤

1. 打开设置中心，左边选组。
2. 改值后点「应用」或直接关闭面板，改动即保存；有的组带「恢复默认」。
3. AI 相关的填写见下：先在「AI 与模型」填 API Key、接口地址、模型、协议与思考模式，再调单篇 / 批量预算；然后到「网络代理」按需填代理并可「测试 AI 连接」。
4. 需要环境结论时进「引擎与环境」，那里能看到环境检查的九项结果（只读，可重跑）。
5. 要把问题报给编辑部，用「日志与诊断」：先看日志摘要，再「复制诊断信息（文本）」或「导出为文本文件」。

### 九组分别管什么

| 组 | 管什么 |
|---|---|
| 外观 | 深色模式、界面缩放（带上下限钳制）、按钮配色 |
| 引擎与环境 | 引擎状态行、环境检查结果（只读） |
| 路径 | 引擎目录、私有笔记仓等位置 |
| 日志与诊断 | 活动日志、日志级别、诊断信息复制与导出 |
| 高级与关于 | 恢复默认设置、打开设置文件 / 目录、应用版本与运行环境信息、许可 |
| 窗口与托盘 | 托盘行为、关闭窗口时的处理 |
| 语言与地区 | 界面语言、排序与区域习惯 |
| AI 与模型 | AI 功能总开关、AI 辅助编译修复开关、API Key / 地址 / 模型 / 协议 / 思考模式、单篇与批量预算 |
| 网络代理 | 代理地址与端口、测试 AI 连接（离线检查 Key / 地址 / 模型 / 代理） |

> 「AI 功能总开关」关掉后，所有 AI 入口隐藏、零调用；「AI 辅助编译修复」只控制初排本地修复未成功后的逐稿确认。真实联网前会二次确认并提示本次预算。

## 示例

| 场景 | 去哪组 | 做什么 |
|---|---|---|
| 界面字太小 | 外观 | 调界面缩放，保存即生效 |
| 首页提示引擎缺失 | 引擎与环境 / 路径 | 先看环境检查，再核引擎目录 |
| 换了 API Key | AI 与模型 | 填新 Key，保存后用「测试 AI 连接」验证 |
| 公司网络要走代理 | 网络代理 | 填代理，测试连接 |
| 想把日志发给编辑部 | 日志与诊断 | 复制诊断信息（文本），或导出为文本文件 |

## 限制与已知问题

- **不打包导出**：为免夹带稿件内容，工具只提供「复制诊断信息（文本）」与「导出为文本文件」，导出的文本不含 API Key。
- **设置不会随包走**：设置存在本机用户目录，换机器要重新填；密钥也只存本机。
- **部分项需要重启才彻底生效**：如引擎路径改动后建议重开应用，界面缩放与配色即时生效。
- **预算按 token 计**：超限即退出、不发请求；这里填的是上限，不是承诺花费。
- **只写当前版本**：设置项以本版本界面为准，历史版本差异见[版本记录](../reference/changelog)。
