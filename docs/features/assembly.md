# 整期装配

侧边栏展开「整期装配」后是**一个总览 + 六步流水线**：
**流水线总览 → 检查 tex 信息 → 生成目录 → 编译全部 → 合并文件 → 删除临时文件 → 目录摘要推送**（每一步都是导航里的独立子页）。
总览页一屏看整期进度与各步状态，也可以「运行整期流水线」按顺序跑；进入某个步骤子页后，页顶常驻六段进度带，可单独「运行」这一步。「删除临时文件」一次点击自动校验并执行，可撤销。

## 检查tex信息

扫描一期目录内所有 `.tex`，检查卷期号、年份、作者、页码、字号/行距等出版信息；运行后在期目录写
`信息检查<时间戳>.txt / .json`，界面再用引擎的 `--preview` 读回同一套解析结果（只读，不另写文件），
在下方显示 **10 列**结果表：文件夹 / 卷 / 期 / 年份 / 起–止 / 声明页数 / 实际页数 / 字号·行距 /
第一作者 / 中文标题。声明页数与 PDF 实际页数不符时整行标红、实际页数加粗；中文标题只显示一行，
悬停可看全名。摘要区分三种情况：有需核对项（最多列前 3 条）、页数一致、以及没有可比对 PDF
页数时的「页数一致性未验证」提示。结果卡可「打开报告」；报告 JSON 读不回时表格留空并明确提示，
报告文件仍在期目录。选目录要选整期根目录（含 `01 作者/` 等篇目子目录），不要选 `000` 目录页那层。

## 编译全部

对该期所有稿件逐篇编译（xelatex + biber + xelatex×2），失败会标出具体篇目与日志位置。

## 生成目录

生成整期目录页（标题、作者、页码），可指定模板来源期目录作为版式参照；目录条目与正文标题比对，
断行/缩进按模板校准。步骤内先「预览」：只读显示模板来源、说明与篇目清单，不写任何文件；预览的
篇目可带入栏目表编辑。栏目表存在目录设置 JSON（默认信息检查报告同目录的 `目录设置.json`）：
栏目类型（本期无栏目 / 专栏 / 专辑）、中文栏目名、英文栏目名、主持人。选「专栏」或「专辑」时
四项都必须填写，缺项时「生成目录」不可用并提示缺哪几项；「本期无栏目」不写栏目信息，仍可正常生成。
目录始终列出本期全部稿件：「专栏」勾选只决定哪些篇目带栏目标记（缩进），不删条目；「专辑」自动
把本期全部稿件作为专辑稿件，不提供逐篇勾选或全选/清空。英文行用 `Column:` / `Special Issue:`，
英文名缺失时不会回退中文名。「读取栏目表」重新加载（有未保存草稿时先确认），「保存栏目表」写盘前
先备份原文件为 `.bak-<时间戳>`，文件不是合法 JSON 时拒绝覆盖并提示。「生成并编译」调用引擎
`--place --compile --result-json`，结果读引擎 JSON：中文/英文目录 tex 与 PDF 路径、页数、
人工改动处数、警告；可逐项打开结果。中文或英文目录排出来超过一页时，会自动压缩行距（逐份取
「能排成一页的最宽松值」，不重编本来就是一页的那份、也不改字号和版心）；压到允许下限仍超过一页时
会明确报失败并保持原有 `000` 目录不变，提示人工调整该份目录的行距或断行。

## 删除临时文件

一次点击完成：**自动扫描并校验 → 把可再生的临时文件移入期目录 `.toolbox-trash/` 的回收批次 → 可撤销**。
不需要选清理模式，也没有「先预演」步骤或危险确认词——扫描阶段只读，确认没有风险才动手。

会回收（能证明可再生的文件）：

- 编译辅助文件：`.aux` / `.bcf` / `.blg` / `.out`（有同名 `.tex` 时）/ `.run.xml` /
  `.synctex.gz` / `.fls` / `.fdb_latexmk` / `.toc` / `.lof` / `.lot` / `.nav` / `.snm` / `.vrb` /
  `.DS_Store`；
- 编译日志 `.log`：只回收头部是 TeX 编译输出、且同目录有同名 `.tex` 的那种；
- 有来源的 `.bbl`（同目录有 `.bib`，或 tex 声明了参考文献）；
- `.toolbox-tmp/` 里生成目录留下的中间文件、期目录根下带时间戳的中间 tex
  （`Chinese Content_…` / `contents_…`）与 `目录结果.json`；
- 旧的信息检查报告：每期只保留最新一组（`.txt` / `.json` / `_摘要`），更早的整组回收。

永不回收：最终 `.tex` / `.pdf` / 图片 / 样式 / 文献库 / 设置，被 tex 引用到的文件与目录
（`\input` / `\include` / `\includegraphics` / `\addbibresource` / `\bibliography`），
`original/` / `origin/` / `原稿/` / `源稿/` / `原始稿/` 等来稿目录，备份、历史稿、`*_待核/`、
最新一组信息检查报告、未知文件、符号链接与回收区本身。

运行中可停止：扫描阶段停止不写任何文件；搬移阶段停止会显示「已停止，部分文件已回收」，已搬走的仍可撤销。
扫描或校验失败（目录不存在/读不了、引用缺失、动态路径无法判定等）时一个文件都不动；空候选不建批次。
成功后结果区显示实际回收数、保留摘要与失败原因，可「查看明细」或「撤销本次清理」：撤销按本次批次
原样搬回，目标已有同名文件时**不覆盖**并提示。整期流水线默认不清理，需要在步骤勾选里显式选中清理。
本页不提供永久删除或清空回收站入口——需要彻底腾空间时请到系统文件管理器处理，外壳不代劳。

## 合并文件

把扉页、目录、各篇与封底合并成一个整期 PDF 并重建书签（编委页、封底页、小节书签都有开关），
输出带时间戳的合并文件 —— 交付前的最后一道合成。

合并结果卡同时给出**页数、缺失篇数与名单、warning 条数与摘要**，缺篇/告警用警告色；
只有引擎退出码 0 才写「合并完成」，退出码 1 写「需人工核对」（不是程序出错），
退出码 ≥2 写「本次合并失败」并给失败原因。缺失或 warning 不会被藏在日志里。

运行归属按「本次运行」而不是「上一轮结果」：

- 合并一开始就清掉上一轮结果缓存，结果卡先显示「本次合并正在运行…」；运行中切到别的步骤
  也不会丢本次契约行/缺失/告警，回到合并页仍看到本次结果。
- 停止/取消后结果卡显示「本次已取消/未完成：没有生成本次合并产物」，不写「合并完成」，
  也不把上一轮的 PDF 放在「打开文件」里；若原有目标文件仍在，只标注
  「原有目标未改动（上次结果在 …）」，不自动打开。
- 取消后重跑成功只展示本次产物，「打开文件/打开所在目录/复制路径」只指向本次产物。

旧产物（例如上次运行后文件被移走或损坏）：结果卡明确提示「上次产物不在原位/无法识别」，
不静默显示上次成功，也不改写旧路径；只有本次运行真正成功才产生新产物。外壳不扫描、不改写
历史 `合并*.pdf`。目标路径已存在时仍先弹覆盖确认（「取消」/「覆盖并合并」两个出口）。

## 目录摘要推送

出刊后把整期目录整理成目录摘要 `.docx`（期头、栏目、目录条目、文章摘要）。两个平台**同一个引擎入口**
（`dirpush.py`，判据在 `slcn/pushcopy/`），壳里只选目录、选输出根、显示结果：

- 当期模式：选一期目录，可勾「附英文目录」生成中英对照版；年度模式：选该年任一期目录 + 填年份，
  可指定只纳入某几期（英文/中文逗号、顿号、空格都算分隔符，非法片段整体拒绝并提示），扫描同父目录
  下全部期次、缺期只警告。
- 默认输出根 `~/Documents/sysu/编辑部/目录摘要推送`，可在页面改；**生成成功后**才记住上次路径。
- 输出根是否落在代码仓内由引擎只读命令 `dirpush.py --check-out-root <path> --json` 判定（公开仓 /
  笔记仓 / 稿件仓同一判据，壳不复制这套规则）；在仓内会先提示（文档会变成未跟踪文件），非预览时
  **二次确认**「继续生成/取消」；引擎校验本身失败时明确报错，不静默放行。点「只预演」不写任何文件，
  也不弹仓库确认。
- 结果读引擎 `--json`：落盘文件与大小、篇目与摘要条数、摘要取到率（`abstracts_ok/articles`）、缺摘要项、
  警告；可打开输出目录。`ok=false`（含同名覆盖失败）或退出码非 0 一律按失败展示，不显示成功卡、
  不提供打开按钮；取消或异常不落产物，重跑成功只展示本次新产物。
- macOS 可勾「同时生成年度汇总」顺序跑两趟；Windows 一次只跑一个模式（模式单选）。

## 设置、日志与快捷键

设置页按「引擎 / 外观 / 路径 / AI / 网络代理 / 环境检查 / 日志 / 高级 / 诊断」分组，改动即时保存；
保存失败会 toast 说明并保留原文件，不再静默。网络代理组可先「测试 AI 连接」做离线检查
（Key、接口地址、模型、代理），真实联网测试需二次确认并提示预计花费（默认不点不花）。
高级组有「恢复默认设置」「打开设置文件」「打开设置目录」，恢复默认也要确认。

日志页是全局运行日志：级别筛选（全部/错误/警告/摘要）、自动跟随、复制全部、跳到最新、清空（确认后）；
内存里最多保留 4000 行，超出后裁掉最旧一段；「导出诊断包」把版本、系统、引擎、路径、设置（已脱敏）、
环境检查与最近日志写成文本文件（不含 API Key），确认后写入设置目录并在文件管理器打开。

快捷键与页面按钮同源：`Ctrl+,` 设置、`F1` 帮助、`F5` 刷新/重建、`F9` 运行当前步骤、`Esc` 停止、
`Ctrl+Shift+D` 切换主题、`Ctrl+1…6` 切换页面（帮助页列出同一张表）。

## 运行日志

所有页面共用下半部分的运行日志：**摘要 / 原始两层**可切换；长任务可停止（会连带停止 xelatex）。
日志不写死字体，跟随外观设置的字号/缩放。

## 失败时看什么

Flet 单壳在每步旁边显示状态（待运行 / 运行中 / 成功 / 需核对 / 失败），日志区实时滚动并可切「只看摘要」；
信息检查退出码 2 是失败，编译全部退出码 1 表示「有文章编译失败」（不是程序出错），合并退出码 1 表示
「需人工核对」（结果不完整，见结果卡的缺篇/warning/摘要），合并结果卡与结果条同时给出退出码口径与
末行契约（如「完成。合并文件：…（共 N 页）」）。编译失败请再打开该篇 `.log` 看第一条 `!` 行。
设置页的「环境检查」可随时重跑，失败项给出修复提示；首次启动会主动跑一次，失败不阻塞使用。
