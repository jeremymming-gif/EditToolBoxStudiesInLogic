# 整期装配

> **本页目录**：[一句话定位](#一句话定位) · [入口](#入口) · [前提](#前提) · [操作步骤](#操作步骤) · [示例](#示例) · [限制与已知问题](#限制与已知问题)

## 一句话定位

「整期装配」是**一个整期工作台**：同一页里放六个页签，各自完成一类整期任务——**生成目录**、**排序与改名**、**刷新页码**、**合并 PDF**、**清理临时文件**、**生成推送文案**。它们彼此独立，不要求按某个顺序执行；先跑哪个、跑不跑，由当期情况决定。

## 入口

左侧导航 **工作区 → 整期装配**。页内顶部是固定的六个页签，按下面的顺序排列；每个页签有自己的任务区、结果区，底部共用整期日志：

| 页签 | 做什么 | 底层 |
|---|---|---|
| **生成目录** | 检查 tex 信息、按栏目表生成目录页 | infocheck / toc |
| **排序与改名** | 读取排序候选、预览并应用目录改名、生成排序决策稿 | 候选扫描 / renamefolders |
| **刷新页码** | 按当前编号目录或指定篇目刷新页码、编译并更新目录 | refreshpages |
| **合并 PDF** | 把扉页、编委页、目录、各篇、封底合成整期 PDF | mergepdf |
| **清理临时文件** | 扫描可回收的中间文件，逐项勾选后移入回收站 | cleantemp |
| **生成推送文案** | 生成目录摘要推送用的 docx | dirpush |

页签可按 `⌘1`–`⌘6`（Windows / Linux 为 `Ctrl+1`–`Ctrl+6`）快速切换。顶部[命令面板](./search)（`⌘K` / `Ctrl+K`）里能直接搜到这六个页签与对应的底层操作；旧名称可作为搜索别名，但命令面板与快捷键始终以页签的新名称为准。

旧路由 `issue:compileall`、`issue:produce` 现在只打开「刷新页码」页，不再启动编译，也不会迁移旧的运行状态或报告。

## 前提

- **整期目录结构**：每篇一个子文件夹，篇内是套用本刊模板的 `.tex`（篇文件夹名一般就是「作者」）。选路径时选**整期根目录**，不要选产出的 `000` 开头的目录。
- **TeX**：刷新页码、合并 PDF 与编译目录需要 XeLaTeX + biber；只生成目录 tex、排序改名或只清理临时文件不需要。
- **模板**：目录页与合并后的扉页、封底都来自本刊模板；缺模板时对应功能会直接报错而不是产出半成品。
- **栏目表（可选）**：本期分专栏或专辑时，先在「生成目录」里填好栏目表；不分栏目就保持「本期无栏目」。

## 操作步骤

### 生成目录

1. 点「生成目录」页签，确认整期根目录；工具先跑信息检查，把每篇的文件夹、卷、期、年份、起–止页、声明页数、实际页数、字号·行距、第一作者、中文标题列成表，结果同时落 `信息检查<时间戳>.txt / .json`。**声明页数与实际页数不一致会标红**。
2. 分专栏/专辑时编辑栏目表（类型：本期无栏目 / 专栏 / 专辑；专栏填中英栏目名与主持人；专辑自动纳入本期全部篇目）。栏目表存成 `目录设置.json`，每次读取或保存都留 `.bak-<时间戳>` 备份。
3. 先「预览」核对条目与页码（预览只读，不动产出），再「生成并编译」。**「生成单页目录」默认勾选**：勾选时目录超过一页会自动压缩行距（逐份取最宽松的可用值，不动字号与版心），压到下限仍超页则报失败并保持 `000` 目录不变；**不勾选时允许中英文目录各 1–2 页（跳过压缩）**，任一份达到 3 页及以上同样报错并回滚 `000`。设置随栏目表保存在 `目录设置.json` 的 `singlePageToc` 字段，生成目录与刷新页码共用。

### 排序与改名

1. 点「排序与改名」页签，首次点「读取排序候选」，工具只读扫描当期编号目录并列出候选条目；已确认的排序或排除项会被沿用。
2. 用右侧的移动 / 排除按钮调整顺序。列表里的位置是篇目的顺序位置，不是旧编号前缀。
3. 点「预览改名」核对改名计划，再点「应用改名」并在确认弹窗里确认；工具只在同一父目录内把目录改名为 `01 原主体` 这样的顺序编号。改名是写操作，确认前目录与文件字节不变。
4. 需要把顺序交给编辑部时，用并列的次动作「生成排序决策稿」。排序稿可以直接写到**期目录本身、期内子目录、其父目录或其他可写目录**，DOCX 就落在所选的根下；不可写路径、非目录目标会在写入前被拒绝。

### 刷新页码

1. 点「刷新页码」页签，选好整期根目录。页首先显示范围：没有已确认顺序时按引擎当前识别的编号目录刷新；`N` 是编号目录减去有效排除项，排除 `000` 和非编号目录，不依赖已有正文 PDF 的数量。
2. 需要只处理其中几篇时，在「只编这几篇」里填**顺序位置**，如 `01,03`；留空走整期。这里的编号是列表位置，不是文件夹前缀。填了子集时「重生成目录」不可用，两者互斥，避免组合参数被静默丢弃。
3. 点主动作先发**只读预览**：逐行列出位置、目录名和当前页段，并说明写入范围。子集预览会提示「先编选定篇目，页码有变化或旧页码无法核实时会刷新整期及目录」；整期预览会提示正文 TeX / PDF 与目录产物均可能更新。
4. 核对无误后点「确认刷新」；取消则回到预览，不写任何文件。运行中不可重复提交，改选、换期或成功改名后旧预览立即作废。
5. **目录策略**：刷新默认保留现有目录版式，整期事务按引擎规则更新并编译中英文目录。「重生成目录」在「高级选项」里显式可选，默认关闭；若改名或目录缺项导致现有目录无法按原版式更新，工具会透传引擎原因并提示打开该选项重新预览。

> GUI 的「刷新页码」只有这一个启动动作，后接预览与确认。旧版本里独立的「编译全部」卡片、自动勾选、编译报告展示 / 重试、「运行整期」和 demo 入口本期不再出现在界面上；`Engine/compileall.py` 命令行仍保留，详见 [ENGINE_API](../../Engine/docs/ENGINE_API.md)。

### 合并 PDF

1. 点「合并 PDF」页签，确认整期根目录后点「合并 PDF」。
2. 工具直接调用合并脚本，把扉页 + 编委页 + 目录 + 各篇 + 封底合成整期 PDF，输出 `合并<时间戳>.pdf` 并重建书签；输出文件、嵌套书签、编委页 / 封底选项沿用现有设置。
3. 缺部分 PDF 时按引擎原有行为产出并在整期日志记录；结果区只简报完成或失败和本轮产物。目标文件已存在时先弹确认：取消，或覆盖并合并。

### 清理临时文件

1. 点「清理临时文件」页签发起**只读扫描**，候选原位列出，默认**一个都不勾**。
2. 逐项勾选（或全选 / 取消全选；半选显示「已选 M/N 项」）。日常候选是编译辅助文件、有同名 `.tex` 的日志、可再生的 `.bbl`、生成目录留下的中间文件、较旧的信息检查报告。被正文引用到的文件、符号链接、跳过目录都列为**受保护项**，单列折叠、不可勾选。
3. 确认后移入 `.toolbox-trash`，可「撤销本次清理」；同名文件不会被覆盖。一次清理对应一个回收批次，撤销只还原本批次。

> 只勾你确认已交付、不再需要的东西。扫描或校验失败时**一个文件都不动**；空候选不产生回收批次。

### 生成推送文案

1. 点「生成推送文案」页签，选当期模式或年度模式。当期模式可附英文目录；年度模式选期次、年份与纳入期（逗号、顿号、空格均可，缺期只警告）。
2. 输出目录留空即用默认位置：当期是整期目录下的 `000 Table of Contents/`，年度是文档目录下的「目录摘要推送」文件夹；也可以显式指定 `<输出根>/<YYYY 年第 N 期>/`。
3. 先看结果摘要：落盘文件、大小、篇目与摘要条数、摘要取到率（`abstracts_ok` / `articles`）、缺摘要项与警告。结果为失败时按失败处理，不要手工补。
4. 判定到输出根落在稿件仓内时会先提示并要二次确认；确认后才写文件。当期与年度两种模式都可用，仓内输出确认与同名覆盖说明各只显示一处。

## 示例

一期有 12 篇来稿的《逻辑学研究》，整期根目录 `2026年第3期/`：

| 步骤 | 输入 | 产出 |
|---|---|---|
| 排序与改名 | 12 篇编号目录 + 调整后的顺序 | 目录改名为 `01 …` 至 `12 …`，排序决策稿写在所选输出根 |
| 刷新页码 | 整期根目录（留空子集） | 逐篇正文 TeX / PDF 页码更新，中英目录按需更新并编译 |
| 合并 PDF | 整期根目录 | `合并20261126-112030.pdf`（扉页 + 编委页 + 目录 + 12 篇 + 封底） |
| 清理临时文件 | 整期根目录 | 勾选的 `*.aux / *.log / *.bbl` 等移入 `.toolbox-trash`，可撤销 |
| 生成推送文案 | 整期根目录 + 当期模式 | `000 Table of Contents/` 下的目录摘要 docx |

六个页签互不依赖：某期只想补一份推送文案，就直接跑「生成推送文案」，不必先跑其它页签。

## 限制与已知问题

- **不是流水线**：六个页签各自独立，没有「按顺序执行」这回事；前一页签的结果不会被后一页签自动接着用，每次都要在页签里确认输入。
- **只清理可证明可再生的文件**：判断依据是「这份文件是否还被引用 / 是否还能重新生成」。拿不准的一律列入受保护项，宁可少清。
- **目录页超页**：自动压行距到下限仍超一页就报失败并保持原目录不变，需要人工减条目或改栏目表。
- **合并按本次运行归属**：切页或清缓存不会丢结果；手工停止会显示「本次已取消」。旧产物不在原位时会提示上次产物位置。
- **刷新只写有据可查的范围**：子集按列表位置计算；页码变化或旧页码无法核实时会刷新整期并更新目录。GUI 本期不创建编译报告，也不删除历史报告文件。
- **推送输出需确认**：稿件仓不在本工具的可写范围内；判定到输出落在稿件仓内时会先提示并要二次确认。

失败时按状态看：信息检查退出码 2 是失败；刷新页码退出码 1 表示「有文章编译失败」；合并退出码 0 是完成、1 是需人工核对、≥2 是失败。需要环境结论去[设置中心 → 引擎与环境](./settings)，把信息发给编辑部用「复制诊断信息（文本）」或「导出为文本文件」。
