# 整期装配

侧边栏「整期装配」处理**一整期**的收尾工作，顺序从上到下：

## 检查 tex 信息

扫描一期目录内所有 `.tex`，检查卷期号、作者、页码等出版信息是否齐全、是否与预期一致；
表格会把这些字段列出来，**不再是空的**（旧版本曾只显示表头）。

## 编译全部

对该期所有稿件逐篇编译（xelatex + biber + xelatex×2），失败会标出具体篇目与日志位置。

## 生成目录

生成整期目录页（标题、作者、页码），可指定模板来源期目录作为版式参照；
目录条目与正文标题比对，断行/缩进按模板校准。

## 删除临时文件

把编译中间文件移进 `.toolbox-trash/`（可撤销），不会动 `.tex` / `.pdf` / `.sty` / `.bib`。
出刊前清理，避免把中间文件发给排版厂。

## 本期出刊

按出刊规则做最后编排：汇总 PDF、检查必备项、输出可交付的整期文件。

## 运行日志

所有页面共用下半部分的运行日志：**摘要 / 原始两层**可切换；长任务可停止（会连带停止 xelatex）。
