# 整期装配

> **本页目录**：[一句话定位](#一句话定位) · [入口](#入口) · [前提](#前提) · [操作步骤](#操作步骤) · [示例](#示例) · [限制与已知问题](#限制与已知问题)

## 一句话定位

「整期装配」是**一个整期工作台**：同一页里放四个**彼此独立**的功能，按当期需要单独点、单独跑——**生成目录**、**编译并合并**、**清理临时文件**、**生成推送文案**。它们不组成流水线，也不要求按某个顺序执行；先跑哪个、跑不跑，由当期情况决定。

## 入口

左侧导航 **工作区 → 整期装配**。页内四个功能卡片，每张卡片是一个独立入口：

| 功能 | 做什么 | 底层 |
|---|---|---|
| **生成目录** | 检查 tex 信息、按栏目表生成目录页 | infocheck / toc |
| **编译并合并** | 先编译全部篇目，再把扉页、目录、各篇、封底合成整期 PDF | compileall / mergepdf |
| **清理临时文件** | 扫描可回收的中间文件，逐项勾选后移入回收站 | cleantemp |
| **生成推送文案** | 生成目录摘要推送用的 docx | dirpush |

四个功能各自有「运行 / 停止」，也各自保留自己的结果与日志。顶部[命令面板](./search)（`⌘K` / `Ctrl+K`）里能直接搜到这四个功能页与对应的底层操作。

## 前提

- **整期目录结构**：每篇一个子文件夹，篇内是套用本刊模板的 `.tex`（篇文件夹名一般就是「作者」）。选路径时选**整期根目录**，不要选产出的 `000` 开头的目录。
- **TeX**：编译并合并需要 XeLaTeX + biber；只生成目录或只清理临时文件不需要。
- **模板**：目录页与合并后的扉页、封底都来自本刊模板；缺模板时对应功能会直接报错而不是产出半成品。
- **栏目表（可选）**：本期分专栏或专辑时，先在「生成目录」里填好栏目表；不分栏目就保持「本期无栏目」。

## 操作步骤

### 生成目录

1. 点「生成目录」，确认整期根目录；工具先跑信息检查，把每篇的文件夹、卷、期、年份、起–止页、声明页数、实际页数、字号·行距、第一作者、中文标题列成表，结果同时落 `信息检查<时间戳>.txt / .json`。**声明页数与实际页数不一致会标红**。
2. 分专栏/专辑时编辑栏目表（类型：本期无栏目 / 专栏 / 专辑；专栏填中英栏目名与主持人；专辑自动纳入本期全部篇目）。栏目表存成 `目录设置.json`，每次读取或保存都留 `.bak-<时间戳>` 备份。
3. 先「预览」核对条目与页码（预览只读，不动产出），再「生成并编译」。**「生成单页目录」默认勾选**：勾选时目录超过一页会自动压缩行距（逐份取最宽松的可用值，不动字号与版心），压到下限仍超页则报失败并保持 `000` 目录不变；**不勾选时允许中英文目录各 1–2 页（跳过压缩）**，任一份达到 3 页及以上同样报错并回滚 `000`。设置随栏目表保存在 `目录设置.json` 的 `singlePageToc` 字段，生成目录与整期装配共用。

### 编译并合并

1. 点「编译并合并」，确认整期根目录。
2. 「编译全部」逐篇跑 XeLaTeX + biber + XeLaTeX 两遍；有篇目失败会点名给出篇目与日志位置，其余篇目继续。
3. 编译通过后合并：扉页 + 编委页 + 目录 + 各篇 + 封底，输出 `合并<时间戳>.pdf` 并重建书签。结果卡给出总页数、缺失篇数与名单、warning 条数与摘要。
4. 目标文件已存在时先弹确认：取消，或覆盖并合并。

### 清理临时文件

1. 点「清理临时文件」发起**只读扫描**，候选原位列出，默认**一个都不勾**。
2. 逐项勾选（或全选 / 取消全选；半选显示「已选 M/N 项」）。日常候选是编译辅助文件、有同名 `.tex` 的日志、可再生的 `.bbl`、生成目录留下的中间文件、较旧的信息检查报告。被正文引用到的文件、符号链接、跳过目录都列为**受保护项**，单列折叠、不可勾选。
3. 确认后移入 `.toolbox-trash`，可「撤销本次清理」；同名文件不会被覆盖。一次清理对应一个回收批次，撤销只还原本批次。

> 只勾你确认已交付、不再需要的东西。扫描或校验失败时**一个文件都不动**；空候选不产生回收批次。

### 生成推送文案

1. 点「生成推送文案」，选当期模式或年度模式。当期模式可附英文目录；年度模式选期次、年份与纳入期（逗号、顿号、空格均可，缺期只警告）。
2. 输出目录留空即用默认位置：当期是整期目录下的 `000 Table of Contents/`，年度是文档目录下的「目录摘要推送」文件夹；也可以显式指定 `<输出根>/<YYYY 年第 N 期>/`。
3. 先看结果摘要：落盘文件、大小、篇目与摘要条数、摘要取到率（`abstracts_ok` / `articles`）、缺摘要项与警告。结果为失败时按失败处理，不要手工补。
4. 想先确认不会写到稿件仓，用「只预演」；判定到输出根落在稿件仓内时会先提示并要二次确认，只预演则只判定、不写文件。

## 示例

一期有 12 篇来稿的《逻辑学研究》，整期根目录 `2026年第3期/`：

| 步骤 | 输入 | 产出 |
|---|---|---|
| 生成目录 | 整期根目录 + 栏目表（2 个专栏） | `信息检查20261126-101500.txt / .json`、`000/` 下的目录页 |
| 编译并合并 | 整期根目录（12 篇已编译） | `合并20261126-112030.pdf`（扉页 + 编委页 + 目录 + 12 篇 + 封底） |
| 清理临时文件 | 整期根目录 | 勾选的 `*.aux / *.log / *.bbl` 等移入 `.toolbox-trash`，可撤销 |
| 生成推送文案 | 整期根目录 + 当期模式 | `000 Table of Contents/` 下的目录摘要 docx |

四个功能互不依赖：某期只想补一份推送文案，就直接跑第四张卡片，不必先跑前三张。

## 限制与已知问题

- **不是流水线**：四个功能各自独立，没有「按顺序执行」这回事；前一功能的结果不会被后一功能自动接着用，每次都要在卡片里确认输入。
- **只清理可证明可再生的文件**：判断依据是「这份文件是否还被引用 / 是否还能重新生成」。拿不准的一律列入受保护项，宁可少清。
- **目录页超页**：自动压行距到下限仍超一页就报失败并保持原目录不变，需要人工减条目或改栏目表。
- **合并按本次运行归属**：切页或清缓存不会丢结果；手工停止会显示「本次已取消」。旧产物不在原位时会提示上次产物位置。
- **推送只预演不代写**：稿件仓不在本工具的可写范围内；「只预演」只做判定与提示，不写任何文件。

失败时按状态看：信息检查退出码 2 是失败；编译全部退出码 1 表示「有文章编译失败」；合并退出码 0 是完成、1 是需人工核对、≥2 是失败。需要环境结论去[设置中心 → 引擎与环境](./settings)，把信息发给编辑部用「复制诊断信息（文本）」或「导出为文本文件」。
