# 整期装配

侧边栏展开「整期装配」后是**一个总览 + 六步流水线**：
**流水线总览 → 检查 tex 信息 → 生成目录 → 编译全部 → 合并文件 → 删除临时文件 → 目录摘要推送**（每一步都是导航里的独立子页）。
总览页一屏看整期进度与各步状态，也可以「运行整期流水线」按顺序跑；进入某个步骤子页后，页顶常驻六段进度带，可单独「运行」这一步；危险动作（删除临时文件）会二次确认。

## 检查tex信息

扫描一期目录内所有 `.tex`，检查卷期号、年份、作者、页码、字号/行距等出版信息；运行后在期目录写
`信息检查<时间戳>.txt / .json`，界面再用引擎的 `--preview` 读回同一套解析结果（只读，不另写文件），
在下方显示 **10 列**结果表：文件夹 / 卷 / 期 / 年份 / 起–止 / 声明页数 / 实际页数 / 字号·行距 /
第一作者 / 中文标题。声明页数与 PDF 实际页数不符时整行标红、实际页数加粗；中文标题只显示一行，
悬停可看全名。摘要区分三种情况：有需核对项（最多列前 3 条）、页数一致、以及没有可比对 PDF
页数时的「页数一致性未验证」提示。结果卡可「打开报告」；报告 JSON 读不回时表格留空并明确提示，
报告文件仍在期目录。选目录要选整期根目录（含 `01 作者/` 等篇目子目录），不要选 `000` 目录页那层。

## 编译全部

对该期所有稿件逐篇编译（xelatex + biber + xelatex×2），失败会标出具体篇目与日志位置。

## 生成目录

生成整期目录页（标题、作者、页码），可指定模板来源期目录作为版式参照；目录条目与正文标题比对，
断行/缩进按模板校准。步骤内先「预览」：只读显示模板来源、说明与篇目清单，不写任何文件；预览的
篇目可带入栏目表编辑。栏目表存在目录设置 JSON（默认信息检查报告同目录的 `目录设置.json`）：
栏目类型（本期无栏目 / 专栏 / 专辑）、中文栏目名、英文栏目名、主持人。选「专栏」或「专辑」时
四项都必须填写，缺项时「生成目录」不可用并提示缺哪几项；「本期无栏目」不写栏目信息，仍可正常生成。
目录始终列出本期全部稿件：「专栏」勾选只决定哪些篇目带栏目标记（缩进），不删条目；「专辑」自动
把本期全部稿件作为专辑稿件，不提供逐篇勾选或全选/清空。英文行用 `Column:` / `Special Issue:`，
英文名缺失时不会回退中文名。「读取栏目表」重新加载（有未保存草稿时先确认），「保存栏目表」写盘前
先备份原文件为 `.bak-<时间戳>`，文件不是合法 JSON 时拒绝覆盖并提示。「生成并编译」调用引擎
`--place --compile --result-json`，结果读引擎 JSON：中文/英文目录 tex 与 PDF 路径、页数、
人工改动处数、警告；可逐项打开结果。

## 删除临时文件

三种模式（运行前都会确认「清什么、不碰什么」，全部**先移入** `.toolbox-trash/`，可撤销）：

- **编译临时文件**（默认）：把 `.aux` / `.bbl` / `.bcf` / `.blg` / `.out` /
  `.run.xml` / `.synctex.gz` / `.DS_Store` 移进回收站，不会动 `.tex` / `.pdf` / `.sty` / `.bib` / `.log`。
- **交付收尾（白名单）**：交付前清理 `.ai前/`、`.log/`、备份、`_AI*`、核对报告、`_待核/`、aux 全套等；
  保留 `*.tex/*.pdf/*.bib/*.sty/*.cls`、tex 引用闭包（`\includegraphics/\input/\include/…` 指向的文件与目录）、
  `original/` 与人工交付清单；引用缺失时引擎整批拒绝、一个文件都不动，未识别文件保留并提示。
- **工作区旧件（每期留最新合并 PDF）**：每期 `合并*.pdf` 只留文件名时间最新的一份（固定名 `合并.pdf` 永不删；
  解析不出时间时保守保留），清 `信息检查*/`、旧备份、`*_待核/` 等；固定交付物与人工文件永不删。

出刊前清理，避免把中间文件发给排版厂。清理前可先用「预览」看会动哪些文件、动多少个、回收目录在哪；
预览不写任何文件。真清理跑完横幅上可点「撤销清理」：列出该期 `.toolbox-trash/` 下的回收目录，
选一个原样搬回（成功提示恢复个数；目标已有同名文件时**不覆盖**并提示）。本页不提供永久删除或
清空回收站入口——需要彻底腾空间时请到系统文件管理器处理，外壳不代劳。

## 合并文件

把扉页、目录、各篇与封底合并成一个整期 PDF 并重建书签（编委页、封底页、小节书签都有开关），
输出带时间戳的合并文件 —— 交付前的最后一道合成。

## 目录摘要推送

出刊后把整期目录整理成目录摘要 `.docx`（期头、栏目、目录条目、文章摘要）。两个平台**同一个引擎入口**
（`dirpush.py`，判据在 `slcn/pushcopy/`），壳里只选目录、选输出根、显示结果：

- 当期模式：选一期目录，可勾「附英文目录」生成中英对照版；年度模式：选该年任一期目录 + 填年份，
  可指定只纳入某几期，扫描同父目录下全部期次、缺期只警告。
- 默认输出根 `~/Documents/sysu/编辑部/目录摘要推送`，可在页面改；**生成成功后**才记住上次路径。
- 输出根落在代码仓库内会先提示（文档会变成未跟踪文件），非预览时**二次确认**「继续生成/取消」；
  点「只预演」不写任何文件，也不弹仓库确认。
- 结果读引擎 `--json`：落盘文件与大小、篇目与摘要条数、缺摘要项、警告；可打开输出目录。
- macOS 可勾「同时生成年度汇总」顺序跑两趟；Windows 一次只跑一个模式（模式单选）。

## 设置、日志与快捷键

设置页按「引擎 / 外观 / 路径 / AI / 网络代理 / 环境检查 / 日志 / 高级 / 诊断」分组，改动即时保存；
保存失败会 toast 说明并保留原文件，不再静默。网络代理组可先「测试 AI 连接」做离线检查
（Key、接口地址、模型、代理），真实联网测试需二次确认并提示预计花费（默认不点不花）。
高级组有「恢复默认设置」「打开设置文件」「打开设置目录」，恢复默认也要确认。

日志页是全局运行日志：级别筛选（全部/错误/警告/摘要）、自动跟随、复制全部、跳到最新、清空（确认后）；
内存里最多保留 4000 行，超出后裁掉最旧一段；「导出诊断包」把版本、系统、引擎、路径、设置（已脱敏）、
环境检查与最近日志写成文本文件（不含 API Key），确认后写入设置目录并在文件管理器打开。

快捷键与页面按钮同源：`Ctrl+,` 设置、`F1` 帮助、`F5` 刷新/重建、`F9` 运行当前步骤、`Esc` 停止、
`Ctrl+Shift+D` 切换主题、`Ctrl+1…6` 切换页面（帮助页列出同一张表）。

## 运行日志

所有页面共用下半部分的运行日志：**摘要 / 原始两层**可切换；长任务可停止（会连带停止 xelatex）。
日志不写死字体，跟随外观设置的字号/缩放。

## 失败时看什么

Flet 单壳在每步旁边显示状态（待运行 / 运行中 / 成功 / 需核对 / 失败），日志区实时滚动并可切「只看摘要」；
信息检查退出码 2 是失败，编译全部退出码 1 表示「有文章编译失败」（不是程序出错），合并等步骤只在日志里
报退出码与末行契约（如「完成。合并文件：…（共 N 页）」）。编译失败请再打开该篇 `.log` 看第一条 `!` 行。
设置页的「环境检查」可随时重跑，失败项给出修复提示；首次启动会主动跑一次，失败不阻塞使用。
