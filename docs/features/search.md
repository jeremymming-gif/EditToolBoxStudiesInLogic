# 命令面板与搜索

> **本页目录**：[一句话定位](#一句话定位) · [入口](#入口) · [前提](#前提) · [操作步骤](#操作步骤) · [示例](#示例) · [限制与已知问题](#限制与已知问题)

## 一句话定位

顶部搜索框既是**搜索**也是**命令面板**：搜页面（一级与二级导航）、常用命令与最近记录，回车即跳转或执行。**只搜页面、命令与最近记录；不搜稿件正文与运行日志**——这样既快，也不会把稿件内容带进索引。

## 入口

- 快捷键 `⌘K`（macOS）/ `Ctrl+K`（Windows / Linux）随时打开；
- 或点顶栏的搜索框。

## 前提

- 无需配置，也不联网：索引来自本机界面结构与最近记录。
- 首次打开时索引较空，用一段时间后「最近记录」才有内容。

## 操作步骤

1. 按 `⌘K` / `Ctrl+K` 打开，直接输入关键词，例如「设置」「整期」「查库」。
2. 结果分三类：**页面**（一级 + 二级导航）、**常用命令**（如切换深浅色、刷新引擎状态、运行当前页、停止当前运行、放大 / 缩小 / 恢复 100%、新建单篇）、**最近记录**（最近打开过的页面与功能）。
3. 用上下键选，回车执行；选到页面就跳过去，选到命令就直接跑。
4. 按 `Esc` 关闭。

### 常用快捷键

| 快捷键 | 作用 |
|---|---|
| `⌘K` / `Ctrl+K` | 打开搜索 / 命令面板 |
| `Ctrl+,` | 打开设置 |
| `F1` | 帮助 |
| `F5` | 重新检测引擎 |
| `F9` | 运行当前步骤 |
| `Esc` | 停止当前运行 |
| `Ctrl+Shift+D` | 切换深浅色 |
| `⌘1`–`⌘6` / `Ctrl+1`–`Ctrl+6` | 在整期装配页按视觉顺序切到第 1–6 个页签 |

## 示例

| 输入 | 会得到 |
|---|---|
| `设置` | 设置中心页 + 设置相关的常用命令 |
| `整期` | 整期装配页与页内六个页签（生成目录、排序与改名、刷新页码、合并 PDF、清理临时文件、生成推送文案） |
| `查库` | 引用库 → 查库页 |
| `深浅色` | 「切换深浅色」命令，直接执行 |
| `新建单篇` | 「新建单篇」命令，直接进入单篇初排 |

## 限制与已知问题

- **不搜正文与日志**：这是有意为之——避免把作者稿件内容或运行日志灌进索引；要找正文内容请在编辑器里搜。
- **最近记录只在本机**：换机器或清了配置就没了。
- **页面索引随导航走**：界面改名后，旧名字不再命中，以本版本导航为准。
- **不做模糊纠错**：输入错别字可能搜不到，换用导航里的正式名称更稳。
