# 单篇稿件

侧边栏「单篇稿件」是编辑流程的前四步：**初排转换 → 文献回读校验 → 一校核查 → 合并文件**。

## 初排转换

把作者源文件（`.docx` / `.tex`）转成符合本刊排版规范的 **可编译 `.tex`**。

- **拖拽 / 浏览即用**：macOS 版可以把源文件、输出目录直接从访达拖进输入框（拖到页面空白处也有效）；
  Windows 版点「浏览…」选择，或把路径粘贴进输入框；
- **填写元数据（高级选项，第 63b 批；第 67 批起普通转换的唯一人工元数据入口）**：初排页「高级选项」→「填写元数据…」→ 表单：
  中英文题名 / 多行中英文摘要 / 中英文关键词；作者 1–5（每位中英文姓名、邮箱、单位 CN/EN 动态行；第一作者不可删）。
  空值不覆盖、填了的值**直接进交付产物**；表单优先于 `.tex` 元数据文件；临时 JSON 运行结束即删。
  **模板硬上限：作者最多 5 位（`\myfirstauthor…\myfifthauthor` 槽位，不是可调设置）；每位作者每种语言最多 3 行单位
  （版式容量，第 4 行起溢版）**——到上限时界面会拦住并给可操作提示（删空行 / 合并同单位作者 / 单位合并写到一行或移入脚注）。
  **英文模板无关键词槽位**（英文关键词引擎只提示人工放置）；CN 模板英文摘要页多单位第二行不缩进（轻风险，可人工微调）。
- **正文信息覆盖（旧 7 字段；第 67 批起只作两段式兜底）**：普通转换**不再显示**（同一字段只保留表单一个来源，不双源）；
  勾「AI 协同初排（两段式）」时表单不适用，改由这 7 个字段兜底（只覆盖第一作者/题名/摘要/单位/邮箱；
  多作者请用 `.tex` 元数据文件），第一段生效、第二段从暂存状态继承。
- **元数据文件（高级选项，第 63 批 E2；第 63b 批降级为高级兜底）**：`.doc/.docx` **自动识别已取消**（B2 方案回退、GUI 入口撤下）。
  LaTeX 纯正文稿仍可指上一轮模板稿 `.tex`（高级兜底）；**`.docx` 引擎能力保留，但 = CLI 高级、GUI 不提供、不推荐**
  （仅 LaTeX 通道；提取题名/作者/单位/邮箱/摘要/关键词 → 合成临时 `.tex`，只填第一作者槽位；0 字段/坏 docx/未知二进制 → 退出 2）。
  老式 `.doc` 任何通道都不再转换（第 63b 批起 Mac 界面不再自动转 `.docx`），命令行直接给 `.doc` 会退出 2 提示另存。
  Word 源稿的 `.docx` **英文元数据第二源**（第 76 条）行为不变。
  **两段式 AI 协同暂不支持 Word 元数据文件、也不支持人工元数据表单**（请用内联 7 字段兜底或 `.tex` 元数据文件）。
- **Mac 初排页（第 63 批）**：「高级选项」整行/文字都可点（此前只有箭头可点）。
- **出版信息**：卷、期、年、起止页、收稿日期一次填好，产物页眉/页脚才正确；
- **产物**：`<作者>.tex`、`reference.bib`、模板 `.sty`；《文献核实任务书》（`<名>_文献核实.md`）**第 62 批起普通初排默认不生成**，
  需要时走两段式第一段或 CLI `--verify-refs`（高级）；
- **只读引用库比对（第 58 批起默认）+ 任务书入口变化（第 62 批）**：普通初排日志多一行
  「引用库比对：命中 X / 候选 Y / 未命中 Z（只读，不改产物）」（无引用库静默；`--no-bibdb-verify` 可关）；
  第 62 批起初排页独立「生成参考文献核实任务书」勾选已收敛：需要任务书 → 两段式第一段（见下）或 CLI `--verify-refs`；
  勾「用 AI 处理参考文献（直连 API，会产生费用）」时内部自动带 `--verify-refs`（生成任务书并并入核实结果）。
  命中只用于跳过检索/AI 与任务书提示，**不自动改稿**。
- **AI 协同初排（两段式，默认关）**：勾「AI 协同初排（两段式；外部 chat 免费流程）」→ 第一段只写
  **暂存目录** `<输出目录>/<名_姓>_待核/` + 文献核实任务书（含「附一、初排低置信项」与
  「附二、回填说明」；状态「待人工核实（未交付）」）→ 把任务书交给外部 chat 模型，**要交回两部分**：
  完整 BibTeX 代码块 + 附一 JSON（可放同一条回复；拆成多个文件也行）→ 回界面把回填加进「已选清单」
  （**多文件 / 目录 / 剪贴板**都可，可移除 / 全部清除）、按需勾「一键修改产物（--coop-apply；默认不勾）」
  →「运行第二段」才编译（页面勾「清理编译中间文件」则清中间文件后再交付）、**原子交付**并生成协同记录
  （状态「已交付」）。成功后摘要显示「文献回填 x/y（并入 z 条，未回填 n）｜低置信回复 a
  （应用 b / 仅记录待人工 c）」，**文献回填 0 条时橙色警告**。软件**零上传、零 API、零费用**。
  限制：建议清单第二段跑完才生成；`--coop-apply` 决定须在点「运行第二段」前做（跑完重跑是幂等早退）；
  第 57 批起应用三类：BIB-*→reference.bib、META-*→输出 .tex 的 \my*（不覆盖编辑侧值）、FN-* 仅
  citation_unmatched 唯一命中时脚注→\parencite（写前备份 `<名>.tex.ai前`；其余只列建议待人工）；未做任务书自动分片（多片需手动拆分或多文件 / 剪贴板导入）。
- **可选：全文 AI 核查（第 59 批，默认关；第 63 批取消字符上限）**：两段式面板勾「全文 AI 核查（任务书附正文）」+ 范围单选
  「引用上下文（默认，不设上限）/ 全文（不设上限）」；勾上后第一段任务书在「附二」后多「附三、正文全文/引用上下文」
  （`--coop-fulltext context|full`）。第 63 批起**取消 4 万/8 万字符截断**，整篇写入（保留体积估算/超长提示；
  外部 chat 吃不下时自行分段或改用「引用上下文」）。只写进**本机任务书**、由你自己复制给外部 chat；
  **软件零上传、零费用**；不新增改正文类建议；仅第一段生效。
- **全文 AI 核查（直连 API，第 60 批；第 63 批起默认自动应用，默认关）**：初排页 AI 区勾选后，引擎把正文分片发到
  配置的端点（每片一次请求，**会产生费用**）；生成 `<名>_AI全文复核.md`，并**默认把通过批57安全闸的 BIB/META/FN
  建议自动应用到产物**（`.ai前` 备份、`.ai前` 已存在不覆盖、0 条不写、冲突/漂移拒绝、逐条记录；报告照常生成；
  `--no-ai-merge` 会强制只出报告）。可用「设置」页
  「全文核查结果自动应用」或 `--no-llm-fulltext-apply` 关掉（= 只出报告不改产物，即第 60 批的 report-only 行为）。
  上限：设置页「API 核查字符上限」/ `--llm-fulltext-max-chars N`，**默认 40000**，超限显式截断+警告（不退出），
  **0 = 不限（费用可能显著上升）**。未配置端点/超预算 → 退出 2 且零请求；单片失败标「AI 建议不可用」继续出稿。
  不勾时正文不外发；不加此开关时产物/行为与以前逐字节相同。自动应用后报告标题为「AI 全文复核（直连 API，自动应用）」
  并含「四、自动应用记录」；关掉（或 `--no-ai-merge`）时报告与批60 逐字节相同。
- **AI token 预算**（「设置」页）：单篇预算 / 单批预算默认 30000 / 1000000，0 = 不限，留空 = 不传；
  只约束直连 API 通道，外部 chat 两段式零费用不生效；**第 63 批另加「API 核查字符上限」**（默认 40000，0 = 不限）
  与「**全文核查结果自动应用**」（默认开，走批57安全闸）；
- **编译**：产物可直接编译出 PDF；编译失败会保留 `.log` 与中间文件便于排查。

::: info 旧版模板稿
作者用旧版模板（或把自定义命令放在本地 `.sty`）提交时，工具会按「正文用到且现行模板缺」自动迁移定义；
本地非标准命名的旧模板 `.sty` 不会被错误加载，编译器会给出明确提示。
:::

## 文献回读校验 / 回读·比对报告查看器

第 62 批起页顶标题为「**回读/比对报告查看器（高级：手动并回，离线）**」（侧栏短名不变），**本页不生成任务书**，
需要任务书走两段式第一段或 CLI `--verify-refs`；能力全保留。编辑改完参考文献、交回 `.bib` 后：

- 校验回读的 bib 与正文引用是否一致、格式是否符合本刊规范；
- 输出「回读校验报告」（问题分级 + 提示）；
- 校验通过后，可点 **入藏到引用库** 把这份已核实 bib 存进编辑部引用库。

## 一校核查

按手册的一校规范逐条核查稿件（26 条规则），输出「命中项 / 未命中项」清单；
有命中项属于**需要处理**，不是程序失败（退出码语义在日志里写明）。

## 合并文件

把某一期的多篇 PDF 合并为一册，或按「正文 + 封面/目录」规则拼接；支持撤销。

## 输出约定

| 产物 | 说明 |
|---|---|
| `<作者>.tex` | 初排正文，可直接 xelatex 编译 |
| `reference.bib` | 规范化后的参考文献库 |
| `<名>_文献核实.md` | 参考文献核实任务书（两段式第一段 / CLI `--verify-refs` 才生成；第 62 批起普通初排默认不生成） |
| `<名>_AI全文复核.md` | 全文复核报告（勾「全文 AI 核查（直连 API）」才有；第 63 批起默认自动应用 BIB/META/FN，报告照常生成） |
| `reference.bib.ai前` / `<名>.tex.ai前` | 自动应用前的回滚副本（本次运行被改过才有；重跑会覆盖） |
| `<模板>.sty` | 本刊模板样式（随包提供） |
| `original/` | 原稿归档（不删源文件） |
| `_AI协同记录.md` | 两段式协同记录（回填/并入/拒绝/待人工计数；只有走过第二段交付才有） |
| `<名>_AI建议.md` / `.jsonl` | 低置信建议清单（**第二段跑完才生成**；`--coop-apply` 未勾时只列清单） |
| `*.log` | 编译日志（保留，便于排查） |
