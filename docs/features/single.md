# 单篇稿件

侧边栏「单篇稿件」是编辑流程的前四步：**初排转换 → 文献回读校验 → 一校核查 → 合并文件**。

## 初排转换

把作者源文件（`.docx` / `.tex`）转成符合本刊排版规范的 **可编译 `.tex`**。

- **拖拽即用**：源文件、输出目录都可以从访达直接拖进输入框；拖到页面空白处也有效；
- **正文信息覆盖**：题名、作者、单位、邮箱、摘要、英文题名等字段可人工覆盖（作者稿里的占位符会提示）；
- **出版信息**：卷、期、年、起止页、收稿日期一次填好，产物页眉/页脚才正确；
- **产物**：`<作者>.tex`、`reference.bib`、模板 `.sty`，以及按需生成的《文献核实任务书》；
- **编译**：产物可直接编译出 PDF；编译失败会保留 `.log` 与中间文件便于排查。

::: info 旧版模板稿
作者用旧版模板（或把自定义命令放在本地 `.sty`）提交时，工具会按「正文用到且现行模板缺」自动迁移定义；
本地非标准命名的旧模板 `.sty` 不会被错误加载，编译器会给出明确提示。
:::

## 文献回读校验

编辑按《文献核实任务书》改完参考文献、交回 `.bib` 后：

- 校验回读的 bib 与正文引用是否一致、格式是否符合本刊规范；
- 输出「回读校验报告」（问题分级 + 提示）；
- 校验通过后，可点 **入藏到引用库** 把这份已核实 bib 存进编辑部引用库。

## 一校核查

按手册的一校规范逐条核查稿件（26 条规则），输出「命中项 / 未命中项」清单；
有命中项属于**需要处理**，不是程序失败（退出码语义在日志里写明）。

## 合并文件

把某一期的多篇 PDF 合并为一册，或按「正文 + 封面/目录」规则拼接；支持撤销。

## 输出约定

| 产物 | 说明 |
|---|---|
| `<作者>.tex` | 初排正文，可直接 xelatex 编译 |
| `reference.bib` | 规范化后的参考文献库 |
| `<模板>.sty` | 本刊模板样式（随包提供） |
| `original/` | 原稿归档（不删源文件） |
| `*.log` | 编译日志（保留，便于排查） |
