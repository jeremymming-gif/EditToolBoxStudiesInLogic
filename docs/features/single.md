# 单篇稿件

侧边栏「单篇稿件」是编辑流程的前四步：**初排转换 → 文献回读校验 → 一校核查 → 合并文件**。

## 初排转换

把作者源文件（`.docx` / `.tex`）转成符合本刊排版规范的 **可编译 `.tex`**。

- **拖拽 / 浏览即用**：macOS 版可以把源文件、输出目录直接从访达拖进输入框（拖到页面空白处也有效）；
  Windows 版点「浏览…」选择，或把路径粘贴进输入框；
- **正文信息覆盖**：题名、作者、单位、邮箱、摘要、英文题名等字段可人工覆盖（作者稿里的占位符会提示）；
- **出版信息**：卷、期、年、起止页、收稿日期一次填好，产物页眉/页脚才正确；
- **产物**：`<作者>.tex`、`reference.bib`、模板 `.sty`；《文献核实任务书》（`<名>_文献核实.md`）**第 62 批起普通初排默认不生成**，
  需要时走两段式第一段或 CLI `--verify-refs`（高级）；
- **只读引用库比对（第 58 批起默认）+ 任务书入口变化（第 62 批）**：普通初排日志多一行
  「引用库比对：命中 X / 候选 Y / 未命中 Z（只读，不改产物）」（无引用库静默；`--no-bibdb-verify` 可关）；
  第 62 批起初排页独立「生成参考文献核实任务书」勾选已收敛：需要任务书 → 两段式第一段（见下）或 CLI `--verify-refs`；
  勾「用 AI 处理参考文献（直连 API，会产生费用）」时内部自动带 `--verify-refs`（生成任务书并并入核实结果）。
  命中只用于跳过检索/AI 与任务书提示，**不自动改稿**。
- **AI 协同初排（两段式，默认关）**：勾「AI 协同初排（两段式；外部 chat 免费流程）」→ 第一段只写
  **暂存目录** `<输出目录>/<名_姓>_待核/` + 文献核实任务书（含「附一、初排低置信项」与
  「附二、回填说明」；状态「待人工核实（未交付）」）→ 把任务书交给外部 chat 模型，**要交回两部分**：
  完整 BibTeX 代码块 + 附一 JSON（可放同一条回复；拆成多个文件也行）→ 回界面把回填加进「已选清单」
  （**多文件 / 目录 / 剪贴板**都可，可移除 / 全部清除）、按需勾「一键修改产物（--coop-apply；默认不勾）」
  →「运行第二段」才编译（页面勾「清理编译中间文件」则清中间文件后再交付）、**原子交付**并生成协同记录
  （状态「已交付」）。成功后摘要显示「文献回填 x/y（并入 z 条，未回填 n）｜低置信回复 a
  （应用 b / 仅记录待人工 c）」，**文献回填 0 条时橙色警告**。软件**零上传、零 API、零费用**。
  限制：建议清单第二段跑完才生成；`--coop-apply` 决定须在点「运行第二段」前做（跑完重跑是幂等早退）；
  第 57 批起应用三类：BIB-*→reference.bib、META-*→输出 .tex 的 \my*（不覆盖编辑侧值）、FN-* 仅
  citation_unmatched 唯一命中时脚注→\parencite（写前备份 `<名>.tex.ai前`；其余只列建议待人工）；未做任务书自动分片（多片需手动拆分或多文件 / 剪贴板导入）。
- **可选：全文 AI 核查（第 59 批，默认关）**：两段式面板勾「全文 AI 核查（任务书附正文）」+ 范围单选
  「引用上下文（默认，约 4 万字上限）/ 全文（约 8 万字上限）」；勾上后第一段任务书在「附二」后多
  「附三、正文全文/引用上下文」（`--coop-fulltext context|full`；超限显式「已截断：原 X 字，保留前 Y 字」）。
  只写进**本机任务书**、由你自己复制给外部 chat；**软件零上传、零费用**；不新增改正文类建议；仅第一段生效。
- **全文 AI 核查（直连 API，第 60 批，默认关）**：初排页 AI 区勾选后，引擎把正文按 ≤3 万字/片发到配置的
  端点（每片一次请求，**会产生费用**）；只生成 `<名>_AI全文复核.md`（report-only，不改 `reference.bib`/`.tex`，
  **不自动应用**）；未配置端点/超预算 → 退出 2 且零请求；单片失败标「AI 建议不可用」继续出稿。
  不勾时正文不外发。
- **AI token 预算**（「设置」页）：单篇预算 / 单批预算默认 30000 / 1000000，0 = 不限，留空 = 不传；
  只约束直连 API 通道，外部 chat 两段式零费用不生效；
- **编译**：产物可直接编译出 PDF；编译失败会保留 `.log` 与中间文件便于排查。

::: info 旧版模板稿
作者用旧版模板（或把自定义命令放在本地 `.sty`）提交时，工具会按「正文用到且现行模板缺」自动迁移定义；
本地非标准命名的旧模板 `.sty` 不会被错误加载，编译器会给出明确提示。
:::

## 文献回读校验 / 回读·比对报告查看器

第 62 批起页顶标题为「**回读/比对报告查看器（高级：手动并回，离线）**」（侧栏短名不变），**本页不生成任务书**，
需要任务书走两段式第一段或 CLI `--verify-refs`；能力全保留。编辑改完参考文献、交回 `.bib` 后：

- 校验回读的 bib 与正文引用是否一致、格式是否符合本刊规范；
- 输出「回读校验报告」（问题分级 + 提示）；
- 校验通过后，可点 **入藏到引用库** 把这份已核实 bib 存进编辑部引用库。

## 一校核查

按手册的一校规范逐条核查稿件（26 条规则），输出「命中项 / 未命中项」清单；
有命中项属于**需要处理**，不是程序失败（退出码语义在日志里写明）。

## 合并文件

把某一期的多篇 PDF 合并为一册，或按「正文 + 封面/目录」规则拼接；支持撤销。

## 输出约定

| 产物 | 说明 |
|---|---|
| `<作者>.tex` | 初排正文，可直接 xelatex 编译 |
| `reference.bib` | 规范化后的参考文献库 |
| `<名>_文献核实.md` | 参考文献核实任务书（两段式第一段 / CLI `--verify-refs` 才生成；第 62 批起普通初排默认不生成） |
| `<模板>.sty` | 本刊模板样式（随包提供） |
| `original/` | 原稿归档（不删源文件） |
| `_AI协同记录.md` | 两段式协同记录（回填/并入/拒绝/待人工计数；只有走过第二段交付才有） |
| `<名>_AI建议.md` / `.jsonl` | 低置信建议清单（**第二段跑完才生成**；`--coop-apply` 未勾时只列清单） |
| `*.log` | 编译日志（保留，便于排查） |
