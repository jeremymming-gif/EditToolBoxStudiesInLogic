# 一校核查规则表（《排校手册》/《流程化经验书》→ 可执行规则）

这份文档回答：**手册与经验书里的规范，哪几条已经变成机器检查、怎么判、默认改不改、哪几条不做、为什么。**
权威实现是 [`slcn/proofcheck.py`](../slcn/proofcheck.py)；本文件是它的说明书，规则增删与口径变动必须同步这里。

## 一、定位与口径

- 入口：`python3 proofcheck.py --tex "<初排稿.tex>" [--fix]`；初排转换（Word/LaTeX 两条通道）在写盘前自动调用同一套判据。
- **默认动作四级**：① 初排自动改（白名单 `_PROOF_AUTOFIX_IDS`，只改产物、不碰源稿）；② 仅 `--fix` 可改；③ 只报不改（需人工判断）；④ 只报并标 `noisy`（噪声大，供筛选）。
- **报告口径**：初排已自动改的命中**不进报告**；报告只列需要人工判断的条目（摘要表 + 逐条行号），另给一行「可自动修 N 处」。`--check` 的计数与报告同口径。
- **三层屏蔽**都用 `\x00` 等长哨兵（不用空格，空格会被 `\s*` 吃掉而跨区误报）：文本层挖空注释/数学/宏名/键参数；数学层只留数学区；原始层只挖注释与 verbatim（命令型规则用）。
- 规则分组：`ZH-*` 中文稿，`EN-*` 英文稿，`ALL-*` 通用。语种由初排判定；中文规则不查英文正文，反之亦然。

## 三、判据细则（易错处 + 正反例）

1. **连接号分类（ZH-08/ZH-09）**：短横 `\edash` 给人名、编号、日期、字母序号（大写/缩略语、数字、`表2-9`、`2021-06-16`、`A-105`）；双短横 `\cndash` **只给页码范围**（`第8\cndash 12页`）；一字线 `—` 永不改。反例：`马丁-洛夫`（汉字-汉字）、`$\phi$-世界`（数学紧邻）、小写英文邻、命令参数内 → 保持 ASCII。仅命中 span 内的那一根短杠被替换。
2. **标点与脚注位序（ZH-10/11/21）**：脚注/引文应在逗号前；脚注应在句末标点后（`文本。\footnote{注}`），若写成 `文本\footnote{注}。` 则把标点搬到脚注前。反例：中文括注内 `（作者，\parencite{k}，第8页）` 的逗号不动（同一对括号配对的豁免）；同句出现第二处脚注整句跳过（手册 4.2 例外）；左邻逗号归 ZH-10，不归 ZH-21；冒号 `：` 不作句末标点。
3. **集合竖线（ZH-14）**：`$\{x|x>5\}$` → `\mid`；只改命中 span 内**唯一**一根未被转义的竖线。反例：`$\{x: |x|>5\}$`（成对竖线＝绝对值/条件）、`\|`、`$P(A|B)$`（不在集合）→ 不动。
4. **带括号引用组（ZH-23）**：`（…\ct/\pct/\pcp/\pcpp/\parencite/\cite/\footcite/\textcite{…}…）` 或自带括号的 `\pct/\pcp/\pcpp` 紧跟 `。；` → 标点搬到整组前（`甲说（\parencite{k}）。` → `甲说。（\parencite{k}）`）。正文与脚注内同判。反例：英文半角 `(...)`、不加括号的 `\cite{k}。`、`。\parencite`、`：` 场景、组内已有句末句读、同句两组（整句跳过）→ 不动。
5. **楷体区间（ZH-18/ZH-20）**：只认 `quotation`/`quote` 环境与 `\kaishu` 开关覆盖的区间；区间外的 `\textbf` 不报。反例：`\begin{quotation}\textup{This is fine}\end{quotation}` 不报 ZH-18（已调正）；`\kaishu` 只影响其所在组/后续区间。
   - `EN-03` 映射：`’`→`'`，`“`/`”`→两个反引号/两个单引号，`‘`→一个反引号，`—`→`---`，`…`→`\ldots{}`；只改整行以 ASCII 为主的行（中文题名摘要不动）。

## 四、不做清单（三类）

- **版面类**（单字成行、标点行首、段中公式顶格、英文行内连字符）：要看排版后的 PDF 行末，源码判不了，留给人眼与改版式。
- **语义类**（二元符号间隔、4.2「一句两处脚注各对应一部分」的完全判断、图片清晰度、文献条目内容）：需要理解句子/符号/图像语义，纯正则必然误报；只保留保守启发式（同句多脚注跳过）或交给 `bibcheck.py` 与人工。
- **模板/流程类**（通讯作者页眉、首页空白、行距、校对顺序、参考文献体例中改 bbl 的部分）：是改模板或流程动作，不是逐稿检查项；文献字段已由 `bibcheck.py` 覆盖。

## 六、变更协议（四要素）

2. **对照**：用消融/人工成品核对；命中超过人工成品口径时必须说明属用户已接受的预期差异。
3. **正反例**：在 `tests/test_proofcheck.py` 至少各一条，反例覆盖注释、数学、宏名、键参数；改判据必须同时改反例。
4. **同步**：`RULES`、本表、`GUIDE.md`/`ENGINE_API.md`/`docs/features/single.md` 与初排白名单 `_PROOF_AUTOFIX_IDS` 一起改；文档计数由 `tools/gen_docs.py` 注入，不手抄。
