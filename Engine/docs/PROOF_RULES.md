# 一校核查规则表（《排校手册》/《流程化经验书》→ 可执行规则）

这份文档回答一个问题：**手册与经验书里那些规范，哪几条已经变成机器检查、哪几条没有、为什么。**
权威实现是 [`slcn/proofcheck.py`](../slcn/proofcheck.py)（本文件是它的说明书，规则改动要同步这里）。

- 入口：`python3 proofcheck.py --tex "<初排稿.tex>" [--fix]`（见 `ENGINE_API.md` §五）
- **默认只报不改**：《流程化经验书》原话「并非修改所有匹配项，稍作观察」。
  只有「无歧义」的规则才进 `--fix` 白名单，而且写到**新文件**。
- 三层屏蔽：**文本层**（注释 / 数学 / 宏名 / 键参数挖空）、**数学层**（只显数学区）、
  **原始层**（只挖注释，命令型规则用）。屏蔽用 `\x00` 哨兵而不是空格——
  空格会被 `\s*` 吃掉，规则就会跨过数学区误报（实测踩到过）。
- 规则分组：`ZH-*` 中文稿、`EN-*` 英文稿、`ALL-*` 通用。

### 英文弯引号的替换映射（`EN-03`，2026-10-15 用户确认要处理）

13 份英文稿实测：`’` 1107 个（8 篇）、`“`+`”` 各 439（7 篇）、`‘` 197（5 篇）、`…` 16（6 篇）、`—` 16（5 篇），
全部出现在**英文正文**里（`Kaplan’s`、`Verschueren’s`、`“character”`、`‘now’`、`something—and`）。
按手册 §英文文章 2 的写法替换：

| 原字符 | 改成 | 例 |
|---|---|---|
| `’` | `'` | `Kaplan’s` → `Kaplan's` |
| `“` | `` `` `` | `“character”` → ``` ``character'' ``` |
| `”` | `''` | 同上 |
| `‘` | `` ` `` | `` ‘now’ `` → `` `now' `` |
| `—` | `---` | `key — really` → `key --- really` |
| `…` | `\ldots{}` | `then … nothing` → `then \ldots{} nothing` |

判据：只在**整行以 ASCII 为主**的行上改（英文模板会打印中文题名摘要 `\mytitleCN`，
那些位置的中文标点是对的）。

## 三、没有实现（以及为什么）

手册里还有一批规范，**故意没有做成规则**，因为判据不在文本本身上：

| 手册/经验书 | 为什么不做成规则 |
|---|---|
| §常规 1「避免单字成行」、2「避免标点位于行首」 | 这是**排版后**的版面问题（要看 PDF 的行末），不是源码能判的；仍需人眼或改版式 |
| §常规 4.2「一句话两处脚注、各对应一部分 → 都放标点前」 | 要理解句子结构，机器判不了「明显各对应一部分」；B-273 起 `ZH-21` 只用「同句已有另一处脚注 → 整句跳过」的保守启发式，避免误报 |
| §常规 7 连字符的三种形态（短横/双短横/一字线） | **已实现，默认初排自动改**（`ZH-08`，2026-10-28 选项 A）：**短横 `\edash`** 用于人名/编号/日期/字母序号（`让\edash 雅克·卢梭`、`表2\edash 9`、`2022\edash 10\edash 08`、`3-a`、`A\edash 级别`）；**双短横 `\cndash` 只用于页码范围**（`第8\cndash 12页`，由 `ZH-09` 管）；**一字线 `—`** 是半个破折号（`北京—上海`），永不改。新口径：小写英文邻／汉字-汉字／数学区／命令参数保持；大写·缩略语、数字、日期、编号、汉字+数字 → `\edash `。5 期 54 份人工成品实扫：ZH-08 命中 419（可改 326，只报 93——均为数学紧邻）；CJK-CJK 0 改动、数学模式 0 改动、`--` 非页码 0 改动。人工成品现有 `\edash` 仅 179 处、CJK-CJK 窄子集先例 19 处，故这 326 处与人工 ASCII 写法不同属用户 2026-10-28 已接受的预期差异 |
| §数学环境 1「二元符号间隔（`a{+}b`）」 | 要理解符号在本处的语义（是不是二元运算），纯正则必然误报 |
| §数学环境 2 圆圈序号、`\defdot` 等着重号 | 是"怎么写"的模板问题，作者照模板写即可，**proofcheck 不做检查**。（`⑴…⒇`、`①…⒇` 的规范化已由初排预校正 `slcn/rules.py:normalize_unicode_punct` 统一成 `（1）…`，这里不重复查） |
| §数学环境 5「段中插入公式后顶格」 | 版面问题 |
| §插入图片的三种对策 | 需要看图片清晰度（要打开 PDF 放大看），不是文本规则 |
| §英文文章 1「引文用 quotation 环境、不再加引号」 | 可做（检查 `quotation` 里是否又加了引号），但样本太少，先不做 |
| §英文文章 6「单词行内溢出加连字符」 | 版面问题 |
| §模板控制 1「通讯作者页眉处理」、2「首页空白」、3「行距」 | 是**改模板**的一次性操作，不是逐稿检查项 |
| §间隔 1–3（`\hspace`/`\vspace`/`\phantom`） | 版面微调 |
| §参考文献（8 条） | 绝大部分已由 `bibcheck.py`（字段与体例）与任务书（联网核实）覆盖；`JC Beall`、多音字姓氏那两条是**编译流程**（改 `firstinits`、改 bbl），不属于逐稿检查 |
| 经验书「校对顺序」四步 | 是流程建议 |
| 经验书 其他（邮件、VScode、第三方工具） | 与稿件无关 |

## 四、怎么加一条新规则

1. 先在**真实稿子**上量一遍（`out/corpus/` 69 份 + 手边的成品），确认命中不是噪声；
2. 在 `slcn/proofcheck.py` 的 `RULES` 里加一条：`id / title / basis（写明出处）/ pattern / advice`，
   并选对 `scope`：正文文本用 `text`、数学里的用 `math`、命令本身用 `raw`；
3. 判据要能说出「为什么这条是错的」，判不准的**标 `noisy=True`** 或干脆只报不改；
4. 在 `tests/test_proofcheck.py` 加**正例 + 反例**（反例至少覆盖：注释里、数学里、宏名里）；
5. 更新本文件的表格。
