# 每篇交付清单（模板）

> **用途（task-79 方案 C，2026-10-19）**：初排稿交给下一环节或交接给同事前，复制本清单到稿件目录、按实填写。
> **清单只记录，不自动生成、不改变任何现有行为**：引擎/工具箱不读它，也不因它改变产物。
> 用法：把下面「## 清单模板」一节的标题改成 `交付清单：<名_姓>` 存为稿件目录里的 `交付清单.md`，逐项填；不确定写「待确认」，不要留空。

## 清单模板

# 交付清单：<名_姓>

- 稿件标识：<期号 / 篇名 / 目录序号>；语种：<中文 / 英文>；初排日期：<YYYY-MM-DD>
- 所用模板：`编辑笔记/模板文件/SLCN-MIX.sty`（英文为 `SLEN.sty`；覆盖模板则写实际文件）
  - 模板 sha256：<shasum -a 256 模板文件的输出>；产物内 sty：`<名_姓>/SLCN-MIX.sty`，sha256：<…>
- 源稿：`original/<源文件名>`；sha256：<…>（多文件稿把主文件/元数据文件都列出）

- 审阅件集合（交付时应在；缺的写「已跳过」+原因）：
  - [ ] `<名_姓>.tex`（初排稿）
  - [ ] `<名_姓>.pdf`（`--compile` 生成；未编译写「未编译」）
  - [ ] `reference.bib`
  - [ ] 模板 `.sty`（与「所用模板」一致）
  - [ ] `.log`（**刻意保留**，编译出错排查用）
  - [ ] `original/`（源稿归档；工具只读，交付时不动）
  - [ ] `<名>_文献核实.md`（`--verify-refs`；未生成写「未生成」）
  - [ ] `<名>_一校核查.md`（一校核查；未跑写「未跑」）
  - [ ] `<名>_回读校验报告.md`、`<名>_参考文献核对.txt`（本次有就列）

- 已生成 / 已跳过（逐条写清，避免交接时误以为丢件）：
  - 已生成：<…>
  - 已跳过：<…>（原因：未勾选 / 无源 / 等编辑部决定）

- 人工确认（全部勾上才交下一环节）：
  - [ ] 参考文献已核对（以官方来源/源稿原文为准；AI 结果已复核）
  - [ ] 一校核查报告已逐条处理（未处理项已说明）
  - [ ] 图表、公式、脚注已人工过目（编号 / 引用位置 / 页码）
  - [ ] 三校后编号与目录已定（`10 Bo_Chen`、目录页；未到该环节写「未到」）

- 保留 / 清理状态：
  - [ ] 已跑 `--clean`（只删编译中间件：`.aux .bbl .bcf .blg .out .run.xml .synctex.gz .DS_Store`）
  - [ ] 未删 `.log`、未动 `original/`（`--clean` 的固定边界）
  - [ ] 为排查保留了中间件：<列文件名或「无」>

- 备注 / 遗留风险：<人工待核、已知差异、下环节注意>

> 字段口径与保留策略见 `Engine/docs/GUIDE.md` §3.2「审阅件集合 + 交付清单」；sha256 计算：macOS `shasum -a 256 <文件>` / Windows `certutil -hashfile <文件> SHA256`。
